## 26.2 分页 (Pagination)

### 测试位置 (任选)
- `/sales/orders`
- `/procurement/orders`
- `/warehouse/materials`

### 测试点
1. **页码跳转**:
   - 点 `> ` 下一页, URL 参数 page 变化
   - 点 `< ` 返回
   - 输入页码 "99999" 跳转 → 应提示 "超出范围" 或定位最后页
2. **每页多少**:
   - 下拉选 `10 / 20 / 50 / 100`
   - 切换后数据刷新
3. **边界**:
   - 只有 1 页时, 上下页按钮 disabled
   - 空列表时 pagination 应隐藏或显示 0 条
4. **跨页勾选**:
   - 勾第 1 页 5 条, 切第 2 页
   - ✅ 第 2 页勾选清空 (或提示)
   - 回第 1 页, 之前勾选**丢失** (产品决策)

### ✅ PASS
- 分页响应快 (< 500ms)
- Network: `GET /list?page=1&size=20` 参数正确

## 26.8 Toast / 消息提示规范

### 4 种类型
| 类型 | 颜色 | 使用场景 |
|------|------|---------|
| success | 绿 | 操作成功 |
| error | 红 | 失败 (含后端 error) |
| warning | 黄 | 警告 / 非阻塞提示 |
| info | 蓝 | 普通信息 |

### 规范
- 位置: 统一 (推荐右上角)
- 时长: success 3s, error 5s (给用户读)
- 同时多个 toast: 纵向堆叠
- 超长文本: 多行, 不截断

### 批量错误报告
- 导入 Excel 10 条, 5 条失败
- ✅ 弹对话框显示失败明细 (行号 + 原因)
- 不要用小 toast 只报 "失败"

## 26.12 空/错误/加载状态

### 空状态
- 列表 0 条时显示 Empty 图片 + "暂无数据" + 提示新建
- 不应只显示空白表格

### 加载状态
- Skeleton 骨架屏 (Element Plus 内置)
- 或 Loading mask
- 时长 > 3s 显示 "仍在加载..."

### 错误状态
- 接口失败 → 显示重试按钮
- 404 → 友好页
