# 86. 失败路径 + 恢复手册 (81-85 共用)

**目标**: 演示时 95% 时间花在失败恢复, 客户看的就是"出问题怎么办".
**原则**: 每个失败场景给 **现象 → 根因 → 恢复步骤 → 观测字段**

> **本文专讲**: **业务流程级**恢复 — 报工驳回 / 扫码歪 / 库存不足 / 排班冲突 / 批次过期 / 跨端数据不一致.
> **不在本文**:
> - 表单重复提交 / 空值 / 非法输入 → §24
> - 网络断 / token 过期 / 5xx → §33
> - **乐观锁 409**: 通用语义见 §24.7, 网络层见 §33.1.7, 本文 §86.4 只补**业务特例**.

---

## 86.1 网络断 (RN 端)

| 场景 | 恢复 |
|------|------|
| RN 报工提交网络断 | 本地 AsyncStorage 存草稿 → 联网自动同步 (§09) |
| RN 扫码时断网 | 扫码结果缓存, 联网后提交 |
| 草稿同步冲突 (409) | 提示"数据已更新, 请刷新后重做" → 重拉最新 + 人工合并 |
| 同步中 APK 被 kill | 重启后 `/sync/pending` 自动续传 |

**观测**: RN AsyncStorage key `pending_reports[]`, `sync_failed[]`

---

## 86.2 扫码失败

| 场景 | 根因 | 恢复 |
|------|------|------|
| QR 损坏/脏污 | 物理破损 | 手动选下拉 (兜底 UI) |
| 扫到过期批次 | `expire_date < NOW()` | 提示"批次已过期", 拒绝领料 |
| 扫到其他工厂批次 | factory_id 不一致 | 403 Forbidden, 跨工厂阻断 |
| 扫到 INSPECTING 批次 | 品控冻结中 | 拒绝, 提示 "批次冻结观察" |
| 员工工牌丢失 | 无 QR | 主管代录 + 签字 (需 foreman 权限) |

---

## 86.3 审批/处置失败

| 场景 | 恢复 |
|------|------|
| foreman 驳回报工 | operator RN 收推送 + 备注原因 → 修改重提 (PENDING → REJECTED → PENDING) |
| foreman 离开超 2h 未审 | 升级车间主任 (告警 §27 alerts) |
| 排班冲突 (设备/人员) | `/scheduling/alerts/unresolved` 红色告警 → acknowledge + reschedule |
| 处置规则冲突 | `/quality-disposition/pending` 堆积 → 管理员 approve 或改规则 |
| 发票开具失败 | PDF 上传超时 → 本地保存 + 重试按钮 |

## 86.4 并发冲突 (乐观锁 409)

| 场景 | 表现 | 恢复 |
|------|------|------|
| 两人同时改同一批次 | HTTP 409 + "version mismatch" | 重拉 + 人工合并 |
| 同时审批同一报工 | 409 | 后到者看到"已处理"状态 |
| 同时领同一批次 | `reserved_quantity` CAS 失败 | 提示"库存已被占用", 重选批次 |
| SO 已发货后改价 | 409 + "status SHIPPED 不可改" | 走财务红冲流程 |

**观测**: `rowVersion` 字段, backend 日志关键字 `OptimisticLockException`

---

## 86.5 库存/批次异常

| 场景 | 恢复 |
|------|------|
| 领料时库存不足 | 拒绝 + 提示缺口量 → 采购补料或改计划 |
| FIFO 批次已用完 | 自动切下一批次, 均价重算 |
| 盘点差异 > 阈值 | 生成差异单 → 主管审批 + 原因备注 |
| 批次到期未消耗 | 自动 `EXPIRED` + 通知 warehouse 处理 |
| 负库存 | 阻断 (业务规则), 记录 audit log |

---

## 86.6 跨端数据不一致

| 场景 | 恢复 |
|------|------|
| Web 改员工角色, RN 当前登录 | 推送踢下线 (策略 A) 或下次登录生效 (策略 B), 见 §14.10 |
| Web 撤销计划, RN 已开始报工 | 优先 RN 已完工量 → Web 显示部分完工 |
| Web 改 SO 后 RN 看旧 | 下拉刷新即时 (§14.11) |
| RN 上传的照片 Web 打不开 | 检查 OSS 权限 + 路径映射 |

## 86.7 常见错误码速查

| HTTP | 含义 | 常见场景 |
|------|------|---------|
| 401 | Token 过期 | 前端自动刷新 refreshToken (§JWT) |
| 403 | 跨工厂 / 权限不足 | 检查 JWT factoryId 与 URL 参数一致 |
| 409 | 乐观锁 / 唯一键冲突 | 见 §86.4 |
| 422 | 业务校验失败 (如产能超) | 按提示调整数据 |
| 429 | 速率限制 | 退避重试 |
| 500 | 后端异常 | 查 `/logs/cretas-prod.log` |
