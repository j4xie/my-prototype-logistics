## 22.2 应收账款 (`/finance/ar`)

### 22.2.1 AR 列表
**账号**: `finance`
1. 进 `/finance/ar`
2. 列表显示所有未结清 SO

### 字段
| 字段 | 说明 |
|------|------|
| SO 编号 | - |
| 客户 | - |
| 订单金额 | 总额 |
| 已开票 | 开票金额 |
| 已收款 | 收款金额 |
| **未收金额** | 订单 - 已收 |
| 账期 | 如 30 天 |
| 账龄 | 1-30 / 31-60 / 61-90 / 90+ |
| 催款状态 | 未催 / 已催 |

### 22.2.2 筛选
- 按客户
- 按账龄 (> 90 天)
- 按订单状态

### 22.2.3 应收汇总
- 顶部 KPI:
  - 总应收: ¥XXX
  - 逾期应收: ¥XXX
  - 本月收回: ¥XXX

### 22.2.4 催款
1. 行点 "**催款**"
2. 弹框:
   - 催款方式: 电话 / 邮件 / 短信
   - 催款内容
3. 确定

### ✅ PASS
- 记录催款历史
- 客户状态变 "已催"

### 22.2.5 导出对账单
- 点 "**导出对账单**"
- 选客户 + 账期
- 下载 PDF/Excel

## 22.3 应付账款 (`/finance/ap`)

### 22.3.1 AP 列表
- 显示所有未付采购单
- 字段类似 AR (订单/供应商/已开票/已付/未付/账龄)

### 22.3.2 付款申请
1. 行点 "**申请付款**"
2. 字段:
   - 付款金额 (自动填未付)
   - 付款方式
   - 预计付款日
   - 备注
3. 提交审批

### 22.3.3 付款执行
- admin 审批通过后
- finance 录入实付:
  - 实付金额
  - 实付日期
  - 流水号
- 供应商余额更新

## 22.4 成本核算 (`/finance/costs`)

### 22.4.1 成本列表
- 按订单 / 按产品 / 按期间

### 22.4.2 成本拆解 (⚠️ §13.1.4 说当前只显示总利润)
- V1 现状: 只显总利润
- V2 规划: BOM 成本 + 历史成本 + 实际成本 + 毛利

### 22.4.3 成本分析报表
- 月度成本趋势
- 成本超标预警 (实际 > 标准 10%)

## 22.6 月结 / 结账

### 22.6.1 月结操作
- 点 "**月结**" 按钮
- 锁定本月所有财务数据 (不可改)
- 生成月度报表

### 22.6.2 结账后验证
- 本月已结束 → 新增收款/付款进入下月
- 需管理员才能反结账
