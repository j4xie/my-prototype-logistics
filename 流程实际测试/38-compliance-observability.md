## 38.2 敏感数据导出水印

- 导出 PDF/Excel 含:
  - "机密" 红字水印
  - 导出人 + 时间
  - 工厂名称

### 测试
- 多角色导出同数据, 水印信息不同
- PDF 水印不可删除

---

## 38.3 审计日志

### 入口
`/system/logs` / `/system/audit`

### 必记操作
| 动作 | 必记 |
|------|------|
| 登录/登出 | ✅ |
| 用户 CRUD | ✅ |
| 权限修改 | ✅ |
| 删除记录 | ✅ |
| 金额修改 (SO/发票/收款) | ✅ |
| 敏感导出 | ✅ |

### 日志字段
- 操作人 / 时间 / IP / 动作 / 旧值 / 新值 / traceId

### 保留期
- ≥ 1 年 (合规)
- 可查询, 可导出

---

## 38.4 GDPR/隐私

- 用户可请求删除账户 → 30 天后彻底删
- 数据导出给用户 (可携带性)
- 隐私政策链接

---

## 38.5 可观测

### 追踪
- 每 API 带 `X-Trace-Id` header
- 前端 console 打印 traceId 便调试
- 后端日志关联 traceId

### 错误上报
- Sentry / 其他: 未捕获 exception 自动上报
- 含用户信息 (脱敏后)
- 用户可复现步骤

### 监控 Dashboard
- 响应时间 (p50/p95/p99)
- 错误率
- QPS
- 慢 SQL
