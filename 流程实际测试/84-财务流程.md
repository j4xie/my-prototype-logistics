## 84.1 流程总览

```
[SO 审核] 销售订单审核 + 交期确认
    ↓
[采购] 按 BOM 生成采购单 + 供应商价
    ↓
[收货] 实际到货 + 移动均价更新原料单价
    ↓
[生产] 领料消耗 (按移动均价结转)
    ↓
[完工入库] 成品移动均价 = (人工+原料+制造费用) / 产量
    ↓
[出货] 成品出库 (按 FIFO 或移动均价)
    ↓
[开票] ⭐ G1 按税率分组开票 (9%×2500 + 13%×800)
    ↓
[收款] AR 回款冲销
    ↓
[月结] 存货月结 + 成本结转 + 毛利计算
```

## 84.3 Step-by-Step (核心段)

### Step 1: SO 审核 + 应收挂账
- `/sales/orders` → 审核 → 生成 AR 单

### Step 2: 采购 + 移动均价
```
原库存: 100kg @ ¥10 = ¥1000
本次到货: 50kg @ ¥12 = ¥600
新均价: (¥1000 + ¥600) / 150kg = ¥10.67/kg
```

### Step 3: 领料结转
- 领 30kg → 成本 30 × ¥10.67 = ¥320.10 计入 WIP

### Step 4: 完工入库
- 成品均价 = (材料 + 工时 + 制造费) / 产量

### Step 5: 出货 + COGS
- FIFO 或移动均价出

### Step 6: 开票 G1
- 见 §84.2

### Step 7: 收款
- AR 部分冲销 / 全额冲销

### Step 8: 月结
- 存货对账 + 成本核算 + SKU 毛利报表
