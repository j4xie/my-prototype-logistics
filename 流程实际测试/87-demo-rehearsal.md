# 87. 演示前 2 小时演练脚本

**触发时机**: 客户演示开始前 2 h
**操作者**: 讲解人 + RN 操作人 (建议 2 人组, 单人版本见 §87.5)
**目标**: 把 §80.9 K 级 60 min 路径连跑一遍, 暴露数据/UI/性能问题, 留 1 h 修.

---

## 87.1 演练时间轴 (2 h)

| 时段 | 做什么 | 耗时 | 产出 |
|------|--------|------|------|
| T-120 ~ T-100 min | 环境 + 数据铺齐 (§79 全 15 项) | 20 min | 前置通过 |
| T-100 ~ T-95 min | 失败自测 (§86.8 全 6 项) | 5 min | 6/6 绿 |
| T-95 ~ T-35 min | ⭐ **连跑 K 级 60 min 完整路径** | 60 min | 记录卡点 |
| T-35 ~ T-20 min | 修卡点 (UI 不显眼 / 数据不够 / 加载慢) | 15 min | 卡点归零 |
| T-20 ~ T-10 min | ⭐ **重跑 G1 税率分组 + 报工** (杀手锏必须无瑕疵) | 10 min | 无瑕疵 |
| T-10 ~ T-5 min | 浏览器/RN 清缓存 + 关无关标签 | 5 min | 干净桌面 |
| T-5 ~ T-0 min | 静默待机 + 深呼吸 | 5 min | 准备好 |

## 87.2 连跑 checklist (对齐 §80.9)

| # | 段 | 保底 | 预算 | 实际 (填) | 卡点? |
|---|----|------|------|----------|------|
| 1 | 开场 RN+Web 并排 | 3 min | 5 | ___ | ☐ |
| 2 | 报工三维 | 7 min | 10 | ___ | ☐ |
| 3 | 动态库存 | 5 min | 8 | ___ | ☐ |
| 4 | 财务月结 + 毛利 | 8 min | 12 | ___ | ☐ |

| 7 | 收尾 Q&A | 3 min | 5 | ___ | ☐ |
| **合计** | | 41 | 60 | ___ | — |

**判定**:
- 实际 ≤ 60 min + 无卡点 → ✅ 可开演示
- 实际 60-75 min 或 1-2 卡点 → ⚠️ 先修卡点再重演
- 实际 > 75 min 或 ≥ 3 卡点 → ❌ **延期或降级演示** (只讲 G1 + 报工)

---

## 87.3 常见卡点 + 现场修复

| 卡点 | 现场修 (< 5 min) | 修不了 (> 5 min) |
|------|----------------|----------------|
| RN 加载慢 (Metro 打包) | 预先热启动 App 放后台 | 跳过 RN 段 / 截图代替 |
| G1 对话框不弹 | 清浏览器缓存 + DevTools Network 看 API | 降级讲 — 只用 §09 截图 |
| SO 没有多税率 | 去 §79.3 SQL 跑一条 UPDATE 补税率 | 用一张事前准备好的 demo SO |
| AI 诊断空白 | 检查 DashScope API Key + 网络 | 展示历史 AI 分析截图 |
| 库存不刷新 | 下拉刷新 / F5 | 走 SQL 展示底层数据一致 |
| 批次过期 | §79 重新生成一批新数据 | 换另一个 SO 演示 |
| foreman 审批慢 | 检查审批列表轮询是否正常 | 手动 F5 推进 |

## 87.4 演讲人心态 checklist

- [ ] 熟读 §81.8 / §82.5 / §83.4 / §85.5 / §88 客户常问话术
- [ ] 记住 G1 金额: 9%×2500 税 225 含 2725 + 13%×800 税 104 含 904
- [ ] 知道 V1 / V2 边界, 遇问不硬编 (参 §82.5 / §83.4 V2 roadmap)
- [ ] 手机/电脑静音, 禁通知
- [ ] 如果某段卡了, **不要原地卡**, 切下一段继续 (SQL/截图兜底)

---

## 87.5 单人演示精简版

如只有 1 人, 优先砍:
- RN 打卡细节 (§82 Step 6) → 口述
- 多窗口并发 409 (§86.4) → 口述 + SQL 截图
- 保留: G1 / 报工 / 库存 / 失败断网 / 财务毛利 — 5 段 ≈ 45 min
