## 88.1 杀手锏类 (G1 税率分组, 必问)

| Q | A | 细节 |
|---|---|------|
| 支持 3 种以上税率吗? | 支持 | 按 items.taxRate 聚合, 几种就几张. §09.7 |
| 可以手动调整分组吗? | V2 规划 | V1 按系统自动, 分组逻辑可配. §09.7 |
| 发票号怎么生成? | 后端规则可配 | 如 `INV-YYYYMMDD-NNN`, §09.7 |
| 客户要合并开一张? | 不推荐 | 违反税法, 如需开发按需加. §09.7 |
| 如果退货后冲红呢? | 走财务红冲流程 | V1 部分支持, 详 §22 |

## 88.2 报工流程 (§81.8)

| Q | A |
|---|---|
| 10 道工序怎么拆? | 每道独立报工, SQL 按 `order_id × product_id × process_id` ROLLUP 聚合 |
| 超耗报警吗? | >5% 红色告警, >10% 强制备注异常原因 |
| 离线怎么办? | RN AsyncStorage 草稿 → 联网自动同步 (§09-mobile) |
| 工牌 QR 丢了? | 主管代录 + 签字 (需 foreman 权限) |
| AI 诊断能调吗? | V2, 可接入行业专用模型 |

## 88.3 智能排班 (§82.4)

| Q | A |
|---|---|
| V1 能全自动吗? | **不能**. 半智能推荐, 计划员最后确认. 全自动 V2. |
| 冲突怎么处理? | 红色告警 + 一键改期 / 换产线 / 人工覆盖 |
| V2 算法是什么? | 遗传算法 / ILP 求解器, 换模/换线成本最小化 |
| 排班历史能回看? | 可以, `/scheduling/plans?status=*` |

## 88.4 品控 (§83.4)

| Q | A |
|---|---|
| V1 AI 识别准确率? | **V1 无 AI**, 人工拍照 + 标记. V2 目标 95%+ |
| 透过塑料盒识别难不? | 是难点 (客户原话), V2 专用模型训练 |
| 异物检出后批次怎么走? | 自动进 `/quality-disposition/pending`, 规则引擎推荐 (隔离/返工/报废) |
| 召回已出货? | 批次溯源 (§85.6) + 召回清单自动生成 |

## 88.5 动态库存 (§85.5)

| Q | A |
|---|---|
| 月底还盘点吗? | 盘点保留, 用来校对系统 vs 实物, 差异单自动记账 |
| 批次追溯多深? | 原料 PO → 批次 → 领料 → 报工 → 成品批次 → DO → 客户, 全链路 SQL (§85.6) |
| FIFO 规则可改吗? | V1 按 `inbound_date ASC`, V2 可按成本/保质期策略 |
| 负库存会发生吗? | 被业务规则阻断, 记入 audit log |

## 88.6 财务 (§84 + §22)

| Q | A |
|---|---|
| 移动均价如何算? | `(原库存 × 原均价 + 新到货 × 新价) / 总量`, §84.3 例子 |
| 月结含什么? | 存货对账 + 成本结转 + SKU 毛利 + 期间损益 |
| 跨工厂合并结账? | V1 单工厂独立, V2 规划 |
| 部分收款可以吗? | 可以, AR 按金额冲销, 余额正确保留 |
