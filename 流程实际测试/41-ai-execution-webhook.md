**来源**: R3 Agent 1

## 41.1 AI 意图执行 (`/api/mobile/{fid}/ai/intent/execute`)

### 核心流程
用户输入自然语言 → AI 识别意图 → 绑定 Tool → 执行 → 返回结果

### 41.1.1 意图执行
- 前端: AI 助手输入框 (侧边栏 / AiEntryDrawer)
- API: `POST /ai/intent/execute`
- Body: `{query, userId, context}`

### 41.1.2 测试用例
| 用户输入 | 期望意图 | 期望执行 |
|---------|---------|---------|
| "今天销售额多少" | QUERY_SALES_TODAY | 查询返数字 |
| "创建销售订单" | SALES_ORDER_CREATE | 跳转新建页 |
| "删除客户 X" | CUSTOMER_DELETE | 二次确认 |
| "你好" | GREETING | 友好回复 |
| "帮我写诗" | (超纲) | 拒绝, 保持业务边界 |

### 41.1.3 Tool 调用追踪
- 每次意图执行后 `/calibration` 查看
- 看匹配的 tool / 置信度 / 耗时 / 结果

### 41.1.4 错误处理
- 置信度低 → 多候选让用户选
- 工具执行失败 → 友好报错
- LLM 超时 → 降级回复

## 41.3 Webhook 异步回调

### 场景
- 报表导出完成 → 回调前端刷新
- 文件处理完成 → 通知
- POS 订单推送 → 接收

### 41.3.1 POS Webhook
- POS 平台调 `/api/mobile/{fid}/pos/webhook/{brand}`
- 前端订阅变化

### 41.3.2 签名验证
- 每 Webhook 请求应有 X-Signature
- 后端验签失败 → 401
- 重放攻击防护 (时间戳 + nonce)

### 41.3.3 重试机制
- 回调失败 → 后端队列重试 (3 次)
- 超过重试 → 死信队列 + 告警
