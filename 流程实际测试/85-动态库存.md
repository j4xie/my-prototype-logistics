# 85. 动态库存流程 (实时变化, 非月盘)

**来源**: 六扇门 Mar 18 会议
**原话**:
> "现在的库存可能就是一个时间节点更新一次, 实际领多少, 整个库存属于一个动态库存"
> "车间领料, 实际使用量, 涉及一个动态库存"

**耗时**: 45 min
**涉及模块**: §05 收货 + §06 领料 + §07 发货 + §23 批次 + §65 RN 扫码

---

## 85.1 痛点 vs 方案

| 痛点 (现状) | 方案 (V1) |
|---|---|
| 月度盘点才更新 | 每笔操作实时 +/- |
| 领料凭经验, 无凭据 | RN 扫码 + 数量录入 |
| 仓库/车间库存不同步 | 单表统一 material_batches |
| 批次混乱 | FIFO + 批次号追溯 |

---

## 85.2 流程总览

```
[采购到货] warehouse RN 扫采购单 → 库存 +N, 批次生成
    ↓
[车间领料] operator/foreman RN 扫批次 → WIP -N, batch.reserved +N
    ↓
[生产报工] 实际消耗录入 (§81) → 原料库存 -N (按实际非计划)
    ↓
[完工入库] 成品批次生成 → 成品库存 +N
    ↓
[发货] warehouse RN 扫 → 成品 -N, 绑 DO/SO
    ↓
[盘点] 定期实盘 → 差异调整单
```

---

## 85.3 Step-by-Step

### Step 1: 收货 (RN warehouse)
1. 扫采购单 PO-xxx → 显示未到货明细
2. 录实到数量 + 批次号 (系统自动或人工)
3. 确认 → 库存 +N, `material_batches` 新增
4. **Web 5-10s 轮询可见** (对齐 `移动端流程测试/14.4/14.8`):
   - `/warehouse/materials` 库存 (`receipt_quantity - used_quantity - reserved_quantity`) +N
   - `/procurement/orders` PO 状态 PARTIAL/RECEIVED
   - 批次字段: `batch_number` / `supplier_id` / `inbound_date` / `receipt_quantity`
   - PO 时间线加 "到货收货 @warehouse"

**注**: `MaterialBatch` 实际无 `source_type`/`source_id`/`parent_batch_id` 字段. 追溯链走 `purchase_order_items` JOIN `material_batches.batch_number` + 业务逻辑关联.

### Step 2: 领料 (RN operator/foreman)
1. 扫批次 QR → 显示库存
2. 录领取量
3. 提交 → WIP 扣, 批次 reserved +
4. Web 可见消耗趋势图

### Step 3: 实际消耗报工 (§81)
- 投入 100 预计 vs 101 实际 → 差 1kg 记超耗

### Step 4: 完工入库
- 成品批次生成 → SKU 库存 +

### Step 5: 发货
- RN warehouse 扫 DO → 成品 -, 批次绑 SO (溯源)

### Step 6: 盘点调整
- 每月实盘 → 差异单 (调增/调减) + 原因
- 审批后调整库存

## 85.5 演示话术

> "现在的库存可能就是一个时间节点更新一次" — 六扇门原话 (月盘点才准). 我们的方案:
> 1. 仓管扫采购单到货 → 库存立即 +N, Web 3 秒可见
> 2. 车间领料扫批次 → WIP 立即 -N, 仓库库存同步扣
> 3. 报工录实际消耗 101kg (BOM 预计 100) → 超耗 1kg 实时记账
> 4. 发货扫 DO → 成品 -N + 绑定 SO (**批次溯源链完整**)
> 5. 任何时点查库存都是**此刻真实值**, 不是上月 30 号的

**客户常问**:
- "月底盘点还要吗?" → 需要, 用来校对系统 vs 实物差异, 差异单自动记账
- "批次能追溯多深?" → 从原料 PO → 批次 → 领料 → 报工 → 成品批次 → DO → 客户, 全链路 SQL 可查 (§85.6)

## 85.6 数据观测 SQL

```sql
-- 实时库存 (真实字段)
SELECT material_type_id,
       SUM(receipt_quantity - used_quantity - reserved_quantity) AS available
FROM material_batches
WHERE factory_id = ? AND status = 'AVAILABLE'
GROUP BY material_type_id;

-- FIFO 取用顺序 (按入库日期)
SELECT batch_number, receipt_quantity - used_quantity - reserved_quantity AS remaining
FROM material_batches
WHERE material_type_id = ? AND factory_id = ?
  AND status = 'AVAILABLE'
  AND (receipt_quantity - used_quantity - reserved_quantity) > 0
ORDER BY inbound_date ASC, production_date ASC;

-- 批次追溯链 (无 parent_batch_id, 通过业务表 JOIN)
-- 原料 → 供应商
SELECT b.batch_number, b.supplier_id, b.inbound_date, s.name AS supplier_name
FROM material_batches b
LEFT JOIN suppliers s ON b.supplier_id = s.id
WHERE b.batch_number = ?;

-- 原料 → 报工消耗
SELECT mc.production_report_id, mc.planned_quantity, mc.actual_quantity
FROM material_consumption mc
WHERE mc.batch_id = ?;
```
