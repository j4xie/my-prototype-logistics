# 33. 错误路径 + 异常恢复 (Happy Path 补充)

> **🟡 R18 QA Smoke (2026-04-17 07:03)**: 3 个 404 API 探针 `/nonexistent-endpoint` / `INVALID-ORDER-ID` / `customers/99999999` 都返回结构化 `{code,message,timestamp,success}` 一致. 发现 minor: Customer 404 message 英文 "Customer not found with id: X" 其他中文 — i18n 不一致. Frontend console logs 404 不 crash. 未测断网/重试/backend 500/DB 断 (但本 session test backend 重启 2 次 systemd 都正常恢复, 算副产品 failure recovery 验证).

**来源**: R3 Agent 3 审计
**耗时**: 30 min (可抽样)

> **本文专讲**: **网络/浏览器级**异常 — 断网 / 后端 5xx / token 过期 / 文件上传中断 / 浏览器刷新中途 / 会话失效.
> **不在本文**:
> - 重复提交 / 空值 / 边界数值 → §24
> - 报工驳回 / 扫码失败 / 库存不足等**业务流程**恢复 → §86
> - **乐观锁 409 主文档在 §24.7**, 本文 §33.1.7 只做通用数据竞态语义描述, 业务冲突细节见 §86.4.

## 33.1 10 类异常 (30+ 测试点)

### 33.1.1 网络中断 (Offline)
**工具**: F12 Network → Offline

| 场景 | 期望 |
|------|------|
| 新建 SO 中断 | Toast "网络异常" + 数据保留 + 重试按钮 |
| 编辑断网 | 字段保留, 不清空 |
| 列表加载中断 | 已加载数据显示, 不白屏 |
| 网络恢复 | 点重试 / 自动同步 |

### 33.1.2 后端 5xx
| 状态 | 期望 |
|------|------|
| 500 | Toast "服务器错误" + 重试按钮 |
| 503 | "系统升级中" 友好页 |
| 超时 (30s+) | 可重试, 不永久卡 |
| 部分成功批量 | "成功 50, 失败 10" 明细 |

### 33.1.3 Token 过期自动刷新 (401) ⭐
1. 清 `localStorage.cretas_access_token` 或 等 30min
2. 触发任何 API
### ✅ PASS
- 自动调 `/auth/refresh`, 续 token
- 原请求自动重发成功
- 2 标签页同时 401 → 只 refresh 一次 (failedQueue 防重)
- Refresh 失败 → 跳 `/login`

### 33.1.4 表单提交中断
- 提交中点浏览器后退 → 提示 "有未保存修改"
- 提交中 Ctrl+R → 阻止或提示
- 提交超时 → 可取消/重试, 保留输入

### 33.1.5 文件上传中断
- 上传 50% 断网 → "上传失败, 可重试"
- 格式错误 → 前端阻止
- 上传中取消 → 清理中间态
- 并发 > 3 上传 → 队列

### 33.1.6 浏览器刷新中途
- 列表加载中 Ctrl+R → 重新加载
- 详情加载中刷新 → 骨架屏
- 编辑未保存刷新 → 弹 "确认离开?"

### 33.1.7 数据竞态 (乐观锁) ⭐
- 2 窗口编同 SO, 后保存返 409 "数据已被修改"
- 刷新后能看到对方改动, 可再改

### 33.1.8 跨标签同步
- A 删记录 → B 列表实时移除 (WebSocket/轮询)
- A 改状态 → B 列表刷新 (5-10s)

### 33.1.9 浏览器崩溃恢复
- localStorage 草稿: `draft_SO_{id}` 保存未提交数据
- 重开后能恢复 (提示用户)

### 33.1.10 后端逻辑错误 (400/422)
- 字段必填缺失 → Toast + 红框
- 业务规则违反 → 友好提示 (不技术细节)
- 保留用户输入不清空
