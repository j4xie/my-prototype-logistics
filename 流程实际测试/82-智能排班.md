# 82. 智能排班流程 (⭐ 排产驱动生产)

**来源**: 六扇门 Mar 18 会议
**原话**:
> "我们先把生产这一块的模块, 再加上这个调度这一块的模块"
> "排产靠经验, 不够智能"

**耗时**: 45 min
**涉及模块**: §27 调度 + §18 HR + §19 设备
**V1 范围**: 基础排班 (手工 + 半智能推荐). 全自动 AI 排班 → V2.
**后端**: `SchedulingController` @ `/api/mobile/{factoryId}/scheduling/*` (30+ 端点已实装)
**扩展**: `SchedulingOptimizationController` / `APSAdaptiveController` / `LinUCBController` (智能推荐底座)

---

## 82.1 流程总览

```
[多 SO 待排产] sales 审核通过的订单池
    ↓
[计划员] 选订单 + 查看产能/设备/人员可用度
    ↓
[系统] 基于 BOM + 工序时间 + 设备产能 + 人员排班推荐排产方案
    ↓
[计划员] 调整 + 确认 → 生成生产计划 + 指派 operator
    ↓
[冲突检测] 设备/人员冲突 → 红色告警
    ↓
[发布] operator RN 收到任务 (§81 报工入口)
```

---

## 82.2 Step-by-Step

### Step 1: 查看待排产计划
- Web `/scheduling/plans` → `GET /scheduling/plans?status=DRAFT`
- 列表按交期/优先级排序, 选 3 个待排

### Step 2: 资源可用度
- 人员: `GET /scheduling/workers/available?date=YYYY-MM-DD` (HR 排班 §18)
- 产线: `GET /scheduling/production-lines` (§19 保养/故障过滤)
- **预期**: 未来 7 天视图

### Step 3: 生成推荐方案
- 点 "智能推荐" → `POST /scheduling/generate` (APS 算法 + LinUCB bandit)
- 人员推荐: `POST /scheduling/workers/recommend` (基于历史 task-history)
- **推荐输出** (甘特图):
  - SO-A → 批次 B1 / L1 / 3/18-3/19 / E001+E002
  - SO-B → 批次 B2 / L2 / 3/19-3/20 / E003
- 成功概率: `GET /scheduling/plans/{planId}/probabilities`

### Step 4: 冲突检测 + 告警
- `GET /scheduling/alerts/unresolved` → 红色告警列表
- 典型 error: 409 冲突 (设备/人员双占) / 422 产能超限
- 处理: `POST /scheduling/alerts/{alertId}/acknowledge` 或 `/resolve`
- 重排: `POST /scheduling/reschedule`

### Step 5: 确认发布 (Web 侧)
- `POST /scheduling/plans/{planId}/confirm` → 批量生成生产计划
- 人员指派: `POST /scheduling/workers/assign`

### Step 6: RN operator 任务接收 + 打卡 (Mobile 侧)
1. operator RN 进 "工作" Tab → `GET /scheduling/workers/assignments?userId=xxx`
2. **同步延迟**: Web 指派 → RN 可见 5-10s (轮询) 或下次进 Tab 即时 (手动刷新) (对齐 §14.5/14.8)
3. 点任务 → 上班打卡 `POST /scheduling/workers/assignments/{id}/check-in`
4. 工作中 (走 §81 报工流程)
5. 下班打卡 `POST /scheduling/workers/assignments/{id}/check-out`
6. 跨端一致 (对齐 §14.8): RN 打卡 → Web HR 考勤 5-10s 可见

## 82.4 演示话术

> "排产靠经验, 不够智能" — 六扇门原话. 我们的方案:
> 1. 计划员选 3 个待排 SO, 点 "智能推荐"
> 2. 系统 3 秒算出: 哪条产线 / 哪组人 / 哪天做 → 甘特图直接展示
> 3. 检测到 L1 产线 3/18 冲突 → **红色告警**, 一键改 3/20
> 4. 确认发布 → operator 手机秒收新任务

**V1 坦诚边界**: 当前是"半智能推荐", 计划员要确认. **V2** 接遗传算法/ILP 全自动最优.
