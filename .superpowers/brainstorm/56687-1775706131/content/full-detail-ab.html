1. 数据模型 — 7 张新表

Layer A: Tool/Skill 配置 (3 张表)
factory_tool_configs
factoryId    VARCHAR(50) ──┐
toolName     VARCHAR(100) ─┤ UNIQUE
enabled      BOOLEAN       │
paramOverrides JSONB       │ 默认参数覆盖
riskOverride   VARCHAR(20) │ 风险级别覆盖
customDescription TEXT     │ 工厂自定义描述
factory_skill_configs
factoryId    VARCHAR(50) ──┐
skillName    VARCHAR(100) ─┤ UNIQUE
enabled      BOOLEAN
customDAG    JSONB         │ 工厂自定义 DAG 步骤
customTriggers JSONB       │ 工厂自定义触发词
priority     INTEGER       │ 工厂内排序
factory_trigger_chains
factoryId    VARCHAR(50)
chainCode    VARCHAR(64)   │ 如 "SO_FINANCE_APPROVED"
eventType    VARCHAR(100)  │ 事件类型
enabled      BOOLEAN
steps        JSONB         │ [{tool, condition, order}]
errorStrategy VARCHAR(20)  │ STOP/CONTINUE/ROLLBACK
description  TEXT
Layer B: 业务逻辑外化 (4 张表)
factory_validation_rules
factoryId    VARCHAR(50)
moduleCode   VARCHAR(64)   │ "sales_order"
ruleCode     VARCHAR(64)   │ "DRAFT_ONLY_EDIT"
condition    TEXT           │ "status != 'DRAFT'"
errorMessage TEXT           │ "只有草稿可编辑"
enabled      BOOLEAN
severity     VARCHAR(16)   │ BLOCK / WARN / INFO
sortOrder    INTEGER
factory_default_values
factoryId    VARCHAR(50)
moduleCode   VARCHAR(64)
fieldCode    VARCHAR(64)   │ "yieldRate"
defaultValue JSONB         │ 95
condition    TEXT           │ 可选: 条件默认值
description  TEXT
factory_formulas
factoryId    VARCHAR(50)
moduleCode   VARCHAR(64)
formulaCode  VARCHAR(64)   │ "ACTUAL_QTY"
expression   TEXT           │ "stdQty / (yieldRate/100)"
variables    JSONB          │ 变量定义
resultType   VARCHAR(20)   │ DECIMAL/INTEGER/BOOLEAN
precision    INTEGER
factory_scheduler_configs
factoryId    VARCHAR(50)
taskCode     VARCHAR(64)   │ "ACTIVE_LEARNING_DAILY"
cronExpression VARCHAR(50) │ "0 0 2 * * ?"
enabled      BOOLEAN
toolOrMethod VARCHAR(100)  │ 执行的 tool 或 method
params       JSONB         │ 执行参数

2. 触发链配置 — Event→Condition→Tool 编排

替代硬编码的 @EventListener, 每个步骤都可以开关/调序/加条件

示例: 销售订单财务审批后的触发链 (SO_FINANCE_APPROVED)
🔔 Event: SalesOrderFinanceApprovedEvent
1
inventory_check_stock 检查成品库存
✅ 启用
condition: always
2
inventory_reserve_stock 预留库存
✅ 启用
condition: step1.result.hasStock == true
3
production_plan_create 自动创建排产计划
⚙️ 条件启用
condition: step1.result.hasStock == false (库存不足时才排产)
4
purchase_suggestion_create 自动采购建议
❌ 六扇门已禁用
六扇门不需要自动采购建议 — 由采购部手动决定
5
notification_send 🆕 六扇门自定义: 通知生产主管
🆕 工厂新增
condition: always | params: {role: "production_supervisor", template: "new_order_approved"}
Canvas 操作: 拖拽调序 · 开关步骤 · 编辑条件 · 新增步骤(从 348 个 Tool 中选择)

4. 完成后能实现的 — 10 个真实场景

场景 1: 新工厂 5 分钟上线
现在: 开发写代码适配 2-4 周
之后: Canvas 选行业模板 → 调整模块 → 发布 → 5 分钟完成
场景 2: 六扇门跳过质检环节
现在: 改 Java 代码 → 部署 → 1 天
之后: 触发链面板 → 禁用 "生产完成→自动建质检" → 发布 → 1 分钟
场景 3: 工厂 A 保质期 180 天, 工厂 B 90 天
现在: 硬编码 plusDays(180), 所有工厂相同
之后: 默认值面板 → 工厂 A: 180, 工厂 B: 90 → 各自生效
场景 4: 调整订单金额计算公式
现在: 硬编码 qty × price × (1-discount)
之后: 公式面板 → 改为 qty × price × (1-discount) + shippingFee → 即时生效
场景 5: 工厂 C 财务审批后自动通知钉钉
现在: 不可能, 需要写代码
之后: 触发链 → 在 "审批通过" 后加一步 notification_send(dingtalk) → 完成
场景 6: 订单 > 5000 元自动触发财务审核
现在: 要么全审要么全不审
之后: 校验规则 → 加条件 "totalAmount > 5000 → 必须财务审核" → 小单直接通过
场景 7: 禁用工厂 D 的 AI 排程
现在: 348 个 Tool 全工厂共享, 无法分工厂
之后: 工具开关面板 → 工厂 D: 禁用 scheduling_* 系列 → 手动排程
场景 8: 工厂 E 生产完成不自动扣料
现在: BatchCompleted → 硬编码自动扣料
之后: 触发链 → 禁用 "batch_consumption_auto" 步骤 → 改为手动扣料
场景 9: 修改凌晨定时任务为白天执行
现在: cron 硬编码 "0 0 2 * * ?" (凌晨 2 点)
之后: 定时任务面板 → 改为 "0 0 8 * * ?" (早上 8 点) → 不用重启
场景 10: AI 对话配置整个工厂
用户: "这个工厂只做熟食, 不需要质检和设备模块, 账期 15 天, 出成率默认 92%"
AI: 自动配置 5 项 → Canvas 预览 → 用户确认 → 一键发布
