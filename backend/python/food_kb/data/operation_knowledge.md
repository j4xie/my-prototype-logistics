## 一、进销存（进货、销售、库存）

### 1.1 原料入库
**状态: 已实现，Web + Mobile 都有界面**
- Web: 仓储管理 → 原材料批次 → 「入库登记」按钮
- 填写: 批次号、原料类型(下拉)、供应商(下拉)、入库日期、数量、单位、总重量(kg)、总价值(元)、到期日期、备注
- 入库类型: 采购订单入库、盘点入库、供应商退货入库、工厂退货入库、其他入库
- Mobile (仓储主管): 首页 → 入库 Tab → 新增入库 → 检验 → 上架
- API: POST /api/mobile/{factoryId}/material-batches

### 1.2 成品入库
**状态: 已实现，生产完成后自动触发**
- 生产批次完成时系统自动创建成品批次（FinishedGoodsBatch）
- 无需手动操作，由 SupplyChainOrchestrator 自动处理
- 查看: Web 销售管理 → 成品库存

### 1.3 成品出库 / 送货
**状态: 已实现，Web + Mobile 都有界面**
- Web: 销售管理 → 出货记录 → 新增出货
- Mobile (仓储主管): 首页 → 出库 Tab → 拣货 → 打包 → 装车 → 签收确认
- 送货单自动关联销售订单，包含客户地址、数量、规格
- 发货后自动扣减成品库存
- API: POST /api/mobile/{factoryId}/sales/deliveries

### 1.4 库存查询
**状态: 已实现，Web + Mobile 都有界面**
- Web: 仓储管理 → 盘点管理 → 库存统计
- Mobile (仓储主管): 首页 → 库存 Tab → 库存查询 / 库存统计
- 支持: 按原料/成品/批次查看，库存金额估值
- API: GET /api/mobile/{factoryId}/material-batches/inventory/statistics

### 1.5 低库存预警
**状态: 已实现**
- 原料设置 minStock（库存预警值）后，低于此值自动报警
- API: GET /api/mobile/{factoryId}/material-batches/low-stock
- AI Tool: 可以对话查询 "哪些原料快缺了"

### 1.6 动态库存
库存随每笔操作实时变化：
- 采购入库 → 原料库存增加
- 调拨发货（领料）→ 原料库存减少（FEFO先到期先出）
- 生产完成 → 成品库存增加
- 销售出库 → 成品库存减少
- 退料 → 原料库存增加

## 三、销售管理

### 3.1 创建销售订单
**状态: 已实现，Web + Mobile 都有界面**
- Web: 销售管理 → 销售订单 → 新增
- 填写: 客户、产品(SKU)、数量、单价、交货日期、业务员、是否含运费、运费金额

- 详情页显示: 全部订单信息 + 业务员 + 含运费/运费 + 实际发货金额
- API: POST /api/mobile/{factoryId}/sales/orders

### 3.2 销售订单财务审核（新功能）
**状态: 已实现**
- 新流程: 新建 → 确认 → 待财务审核 → 财务审核通过 → 生产中
- Web: 销售管理 → 销售订单 → 详情页面

### 3.3 销售订单自动触发排产
**状态: 已实现，自动**

  - 检查库存是否充足
  - 库存不足自动生成采购建议
  - 创建生产计划（PENDING状态）
  - 进行BOM展开

## 五、生产管理

### 5.1 SKU 组装
**状态: 已实现**
- Web: 系统管理 → 产品管理 → 「SKU组装」按钮
- 选模板 + 选客户 → 自动复制配方 → 生成 SKU 编码
- AI: "给汇庭创建墨鱼圈SKU"
- 排产时选 SKU（不是模板）

### 5.2 BOM 配方与成本管理
**状态: 已实现**
- Web: 生产管理 → BOM
- **转换率 Tab**: 新建原料转换关系（转换率 = 1kg原料产多少kg成品）
- **原辅料配方 Tab**: 查看产品的物料明细
  - 产品下拉仅显示成品（已过滤非成品）
  - 物料按类型分类展示（原材料/包材/辅料标签）
  - 「单价（含税）」标注明确
  - 转换率列内嵌到明细表中
  - 自动计算原料投料量
- **成本管理**:
  - 显示总成本: 元/kg + 元/份（可设置标准份量）
  - 人工费用: 弹窗中实时显示「费用小计 = 工序单价 × 操作量」
- 损耗率 = 生产过程额外损耗百分比
- 例: 转换率0.80+损耗5% → 生产1kg成品需1.3125kg原料

## 补充说明

### 经销存 / 进销存
经销存是进销存的口语说法，指进货(采购)、销售(出货)、库存管理三大环节。详见"一、进销存"章节。

### 辅料管理
辅料（调味料、食品添加剂等）在系统中和主原料使用相同的管理方式（原料类型管理）。通过 category 字段区分主料和辅料。六扇门有30-40种辅料/SKU。

### 回款（收款）
客户付款后录入收款记录。详见"四、财务管理 → 4.2 收款"。支持银行转账、支票、现金等方式。

### 仓库管理
系统支持仓库相关的全部操作：入库、出库、库存查询、盘点、调拨、退料。详见"一、进销存"章节。Mobile端仓储主管有完整的入库/出库/库存Tab。

### 摄像头 / 异物检测
系统后端有 YOLO 异物检测模型，支持通过摄像头拍照上传检测。目前需通过API调用，前端界面在规划中。

## 常见问题 FAQ

### Q: 生成调拨单时报"无BOM配置"
先为该产品配置转换率: 生产管理 → BOM → 转换率 → 新建

### Q: 发货时报"库存不足"
先入库补充库存: 仓储 → 入库操作

### Q: 扫码签到失败
确认员工工号正确且已创建: 系统管理 → 员工管理

### Q: 看不到已签到员工列表
员工必须先扫码签到才会出现在蓝色标签中

### Q: SKU和产品模板有什么区别
模板是基础产品（不关联客户），SKU = 模板+客户+配方，排产选SKU

### Q: 调拨单状态流程
草稿 → 已申请 → 已批准 → 已发运 → 已签收 → 已确认

### Q: 进销存怎么用
进(采购入库): 采购管理→订单→审批→到货入库
销(出库送货): 销售管理→订单→出货记录→发货
存(库存管理): 仓储管理→盘点管理/原材料批次
