# 微小异物检测方案评估报告

## Executive Summary

**建议**: 先穷尽YOLO低成本优化（imgsz=1280重训+合成粘贴fine-tune），再评估是否需要异常检测管线
**置信度**: 中高 — Critic对"先优化YOLO"路线的论证充分，三方均认可骨头RGB不可检
**核心风险**: 和牛等复杂纹理食品上异常检测误报率可能远超工业benchmark，导致产线不可用
**时间影响**: 低成本优化路线1-2天可出结果；混合管线需2-4周开发+调优

> ⚠️ **Fact-check notice**: EfficientAD的"2ms延迟"基于高端服务器GPU(A6000)，RTX 3060实际可能10-30ms。CBAM+BiFPN "5.6%提升"来自铝型材缺陷检测而非食品场景。

## 不可检异物（RGB可见光物理限制）

| 异物类型 | 纯RGB检出上限 | 说明 |
|---------|-------------|------|
| 头发（深色，浅色背景） | 60-80% | ≥3mm可检 |
| 蓝色塑料 | 80-90% | 颜色对比明显 |
| 霉变 | 70-85% | 颜色变化明显时可检 |
| **骨头碎片** | **<20%** | 与肉色"nearly identical" |
| **透明塑料** | **<5%** | 无颜色对比 |
| **玻璃碎片** | **<10%** | 透明，需结构光 |

长期建议：对骨头/透明塑料/玻璃引入NIR近红外摄像头或X光辅助。
