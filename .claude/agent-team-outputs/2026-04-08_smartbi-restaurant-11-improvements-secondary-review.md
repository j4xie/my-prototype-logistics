## 附录 B: 99% BOM 真实成本 (Researcher B 业内视角)

### 为什么 99% BOM 在中餐场景几乎不可能

1. **中餐厨师称重习惯**: "学中餐的厨师很少有人用天平", **凭手感是底色** (职业餐饮网/中厨网共识)
2. **食材本身波动**: 同一条花鲢, 重量 ±0.5 斤是正常; 同样叶菜, 本地 vs 外采损耗差 10pp; 同样花鲢夏天/冬天出成率差 5pp (耗氧/缺氧死鱼)
3. **海底捞 5% 损耗是 marketing 话术**, 实测中小餐企 8-15%, 春节 20%+
4. **行业实践**: 70%+ 中小连锁用"月底倒轧成本法" (出库 - 盘点 = 消耗), 倒轧出来的是**总成本**不是**单菜毛利**
5. **没有任何竞品做自动反推校准** — 哗啦啦 / 客如云 / MarketMan 都只做差异提示, **不是因为我们领先, 是这事做不好**

### 真要做 99% BOM 需要的 8 件事 (不要做但要知道)

1. **中央厨房 + 央厨配送**: 主料预切预包, 门店只做组装 — 海底捞/乡村基模式
2. **每个工位电子秤 + 物联网回传**: 称重数据实时入库, 不依赖厨师手感
3. **RFID 食材标签**: 每批食材绑定供应商/单价/日期, 出库扫码自动扣账
4. **闭环 ERP 集成**: 收货 → 入库 → 出库 → 用量 → 销量, 每环节数据自动流转, 不允许手工修改
5. **每道菜固定 SKU**: 招牌青花椒鱼必须是 2.6 斤花鲢 + 2 两青菜 + ..., 不允许"今天用白菜替代"
6. **CCTV + AI 视觉监督**: 后厨摄像头识别厨师是否按 BOM 操作 — 海底捞 2024 已上线
7. **每月第三方盘点审计**: 独立审计师对账, 抓偷料/损耗/赠送
8. **激励重设**: 后厨提成挂钩 BOM 达标率, 不挂钩出餐速度

### 99% 的代价

| 项 | 投入 |
|---|------|
| 央厨建设 | ¥500 万 - ¥2000 万 |
| 物联网称重 | ¥3-8 万/店 |
| RFID + ERP 集成 | ¥50-200 万 |
| 全店 AI 视觉 | ¥10-20 万/店 |
| 第三方审计 | ¥3-10 万/月 |
| **回报周期** | **3-5 年** |

**结论**: 99% BOM 不是软件问题, 是**重资产连锁化 + 流程再造 + 后厨文化重塑**。海底捞投入 10+ 年才达到 95-97%。**任何餐饮 SaaS 厂商承诺 99% 都是骗子**。

### Cretas 的策略

- **做不到 99%, 做 80% (±10%)**, 用知识库+反推校准+财务对照, 给客户**决策可用**的毛利估算
- 实测精度: ±8-12% (B 行业共识), 合同写"差异 <10% 告警"不写"±3%"
- 这就是为什么 Critic 强烈反对原方案的"渠道毛利率"叫法 — 没有 COGS 不能叫毛利率
- **真正护城河 = 行业知识库 (14 个 sub-sector benchmark 是真实弹药) + 多信号融合**, 不是 AI 反推
