## 关键洞察

1. **Phase 2 的语义路由 是 phase 1 单纯"按行数"路由的范式跃迁** — qhj 的 14 个 cache 命中全部依赖 query topic → sheet semantic tag 匹配 (评价 → 4203, 营业概况 → 4189, 团购 → 4190, 营业排名 → 跨 sheet 复合). 这证明 spec §6 ("template_fast_path 命中率应 25%+") 完全可达, phase 2 命中 26.7% 已超阈.

2. **诚实度 (Hallucination Guard) 全程稳定 4.7/5** — phase 1/2 几乎无差异, 说明 numeric guardrail (P2) 工作扎实, 即使 phase 2 数据更丰富, LLM 仍诚实标注 "[毛]/[净]" 与无效数据 (如 qhj-26 "卡号 497M 无业务意义").

3. **gml 持平不退化是巨大成就** — phase 1 已是 4188 商品销量被正确选, phase 2 没破坏这条已 working 路径. Δ=+0.03 在统计噪音内.

4. **xmx 中等提升符合预期** — 4208 数据本身限制了天花板, phase 2 在已有数据上多榨出 4 个 cache 命中 (xmx-07/08/11/19), 已是 phase 2 能做的极限.

5. **Bug G phase 1 → phase 2 的成本**: 单 commit `cf530c7e7`. 收益: 整体 +0.61/5 (+20.5%), qhj +1.32/5 (+56.7%), cache 命中率 6 倍提升. **ROI 极高**.
