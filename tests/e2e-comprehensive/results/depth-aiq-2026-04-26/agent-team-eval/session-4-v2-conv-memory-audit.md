### v2 验证: ✅ 显著成功

3 个核心指标全部命中或超预期:
- 整体得分 **3.66/5** (handoff 推算 3.6+) ✅
- timeout% **3.7%** (handoff 目标 <5%) ✅
- empty% **2.6%** (大幅低于 baseline 11.1%) ✅
- 5 类型预测吻合 4/5 ✅

**结论**: v2 conv memory 投资回报极高 — 成本仅 ~500 token/请求 + 1 SELECT, 收益 +0.45 综合分 + empty 减 91%.

### 后续优化优先级

#### P0 — 修 cache mismatch 漏检 (qhj-fu-15-1 / xmx-fu-29-2)
**问题**: Phase 6 P1 cache_intent_classifier reject 逻辑明显有缺口. 至少 2 个 spotlight 案例仍走错位 cache.
**Action**: 排查 cache_intent_classifier 是否在生产路径生效. 加 audit log 记录哪些 q 被 reject. 重新跑 xmx-fu-29-2 + qhj-fu-15-1 验证.
**Impact**: 修后预期 +0.05 综合分 (3.66 → 3.71), 消除 F1/F2 spotlight 回归.

#### P1 — 防新 timeout (gml 30s+ 5 例)
**问题**: parent context 注入让 LLM 思考链加长,DashScope 偶发 30-55s 超时. timeout% 整体下降但分布变化.
**Action**: 对超过 25s 的请求设硬性 cut-off + 触发 fallback 到 cache_aggregate (如有). 或加流式输出让用户看到进度.
**Impact**: 减 timeout 5 → 2 例,综合分 +0.04.

#### P2 — Coherence 显式标注 (4/270 → 30+/270)
**观察**: 270 答案中只有 4 条显式说"上一轮"或"前一轮", 其它内联引用 (e.g. "套餐"、"32,997 会员"). 用户体验上**显式承上启下**比内联引用更可信.
**Action**: System prompt 加一行: "如果引用上一轮答案的具体数字或实体,请说明 '基于上一轮的 [数字/实体]'". 提升用户感知.
**Impact**: Coherence 5.0 比例 +20%, 综合分 +0.05-0.10.

#### P3 — 动态 prompt 长度 (parent answer 摘要分级)
**观察**: 当前 parent answer 全文注入,长 answer (cache_aggregate 800+ 字) 会挤压 token 预算.
**Action**: 长 parent 答案 (>500 字) 截取关键 KPI + Top N 标签 + 数字, 摘要 200 字内. 短 parent 全文注入.
**Impact**: 节省 30% token,响应快 5-8%, 综合分维持.

#### P4 — Coherence 维度提示词强化 (xmx 类 hard case)
**观察**: xmx 数据稀薄租户即使有 conv memory, 答案仍多"我无法直接 X". 但同样 anchor 用 LLM 推断 (如 W2),Coherence 5.0 可达.
**Action**: System prompt 加"对于 follow-up,优先尝试**基于上一轮数据推断/估算**, 不要默认拒绝".
**Impact**: xmx 综合分进一步从 3.62 → 3.85 +.

### v3 备选方向 (推算 +0.3 - 0.5)

- **完整对话栈** (FU1 + FU2 后 FU3 仍知 FU1): 当前只透传 main → FU,FU 之间互不见. 用户跳跃式提问 (FU1 谈营收 → FU2 谈费用 → FU3 谈"两者关系") 仍受影响.
- **Session-level 数据缓存**: parent 的 cache_aggregate 完整 result blob 传过去,FU 复用全字段而非仅文字摘要.
- **Cross-tenant baseline learnings**: 把 qhj 模板继承率 95% 的成功路径 generalize 到 gml/xmx (现 13/25%).
