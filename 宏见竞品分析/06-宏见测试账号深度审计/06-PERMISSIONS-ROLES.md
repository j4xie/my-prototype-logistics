## 2. 推断 RBAC 模型 (从实测反推)

### 2.1 推断角色 (基于 子菜单 + 部门 button)

**部门 button row** (考勤页实测): 总经理室 / 东莞 / 采购部 / 市场部 / 研发部 / 工程部 / 仓库

**推测角色** (跟部门关联):
| 部门 | 推测角色 | 主要权限 |
|---|---|---|
| 总经理室 | admin / 总经理 | 全模块 + 配置 |
| 销售部 | 销售员 / 销售主管 | 销售单 + CRM, 隐藏利润 (推测) |
| 采购部 | 采购员 / 采购主管 | 采购单 + 供应商 |
| 仓库 | 仓管员 | 库存单 + 调拨 (隐藏价格 — 跟 Cretas C-RBAC-1 一致) |
| 财务部 | 会计 / 财务主管 | 凭证 + 应收应付 + 报表 |
| 工程部 | 工程师 / 工艺主管 | BOM + 工序 |
| 市场部 | 客户/活动 | CRM + 商机 |
| 研发部 | 研发员 | 样品 + 研发项目 |

### 2.2 RBAC 推断 (人力 → 角色管理 子菜单)
- 角色管理 (建角色 + 配置权限点)
- **特殊授权** ⭐ (admin 给员工跨角色临时权限)
- 印章签名管理 (角色级签名权限)
- 员工 ↔ 角色 (一对多)
- 角色 ↔ 权限点 (多对多)

## 3. 推断权限粒度

### 3.1 模块级 (粗粒度)
- 销售员: 销售模块 + CRM (无采购/财务)
- 采购员: 采购 + 供应商 (无销售/财务)

### 3.2 字段级 (细粒度) — 推测有
- 销售员: 销售利润字段隐藏
- 仓管员: 价格字段隐藏 (✅ 直接对应 Cretas C-RBAC-1 / canViewPrice)
- 财务: 全可见

### 3.3 行级 (最细) — 推测有
- 业务员只能看自己客户的销售单 (S-RBAC-1)
- 部门主管可看本部门所有
- admin 全部可见

### 3.4 操作级 (审批权限)
- 工作流引擎驱动 (workflow.hongjian.com)
- 不同节点不同审批人
- 流转规则: 金额 > N 走主管 / 部门 / 财务 多级

## 4. 实测 跨域跳转的权限 (URL pattern)

跳转其他子域时, URL **不带显式 token** — 推测 cookie session 跨域共享 (`document.domain = "hongjian.com"`).

**安全 risk**:
- ✅ 实测 console error: `SecurityError: Failed to read 'document' from "crm.hongjian.com" from "finance.hongjian.com"`
- 部分跨域调用失败, 显示局限
