## 2. 业务流程图 (11 节点)

```
销售订单 → 请购单 → 核价单 ⭐ → 采购底稿 ⭐ → 采购订单
                                          ↓
                          询价单 → 采购变更单 → 质检单 → 采购退货 → 采购入库 → 报表
```

**重大发现 (Cretas 缺)**:
- **核价单** ⭐ — 询价后的"定价审批"中间单据
- **采购底稿** ⭐ — 正式采购订单前的"待定稿"中间状态
- **采购变更单** ⭐ — 订单变更的独立单据 (不是 inline 修改)

### 3.4 关联单据 (linklistarray JSON 字段)

## 7. 业务流程图节点 click 行为验证 ⭐⭐⭐

**关键发现**: 流程图 11 节点不是装饰, **每个节点 click 自动**:
1. 在底部 tab 栏新增 tab (tab 名 = 节点名)
2. iframe 加载对应单据 list (新子域)
3. **跟传统左侧菜单完全可替代**

这是 **U-NAV-1 (业务流程图导航)** 的完整实现, Cretas BentoGrid 可参考此模式:
- 移动端: BentoGrid 顶部加 1×2 "流程图卡片" — 横向 7 节点
- Web-Admin: 模块顶部 horizontal flowchart bar (替代左侧菜单)
- 节点 click → 内嵌新 tab + 路由到对应业务页

**实测节点是 jsPlumb library** (`class="w green jsplumb-droppable _jsPlumb_endpoint_anchor"`) — 节点是**可拖拽连线 endpoint**, 说明 admin 可改流程图 (推测在"系统管理→工作流设置").
