# 固定资产 — Archive (Tier 3 子模块, 浅 audit)

## 入口
顶部菜单 → 财务管理 → 固定资产

## 一句话定义
管理公司固定资产 (设备/车辆/办公设备/不动产) + 折旧 + 报废 + 处置.

## 主要功能 (推测)
- 固定资产档案
  - 资产编号 / 名称 / 类别 / 规格
  - 购置日期 / 购置金额 / 当前净值
  - 使用部门 / 使用人 / 存放地点
  - 折旧方法 (直线/年数总和/双倍余额递减)
  - 折旧年限 / 残值率
  - 状态 (使用中/闲置/报废/处置)
- 月度折旧自动 (脚本 + 凭证 hook)
- 资产盘点
- 报废 / 处置流程
- 资产卡片 (含照片/证书/保养记录)

## 跟 Cretas 的潜在关联
Cretas 完全没有固定资产模块. F006 卤制品工厂的设备 (卤锅/真空包装机/冷库) 走 Cretas 设备管理 (C-DEVICE-LIFE) 但不计折旧.

固定资产 = **会计准则要求**, 中小客户用不到 (个人独资企业可走费用一次性扣除).

## 未来场景假设
- 上市公司 (固定资产 > 总资产 30%)
- 重资产企业 (制造业 / 物流 / 房地产)
- 跨国公司 (多账套合并)

## 跟 F-VOUCHER-HOOK-1 关联
财务流程图含"固定资产成凭证" — 月度折旧自动生成会计凭证:
```
借: 累计折旧 / 制造费用 / 管理费用
贷: 固定资产
```

## 备注
- F006 不需要 (设备 < 100 万)
- Cretas 长期 (Sprint 8+) 大客户场景才考虑
- 标 P3 / Archive
- 跟 长期待摊 / 汇率管理 一组 (大企业财务)
