### 1.2 登录成功跳转

- 成功后跳转 `https://main.hongjian.com/index.jsp`

- 看到的是 "工作台" tab (默认 dashboard)

### 1.3 架构观察 (从 console errors 反推)

**Console 3 errors**:
1. `WebSocket connection to 'wss://localhost.hongjian.com:38580/' failed: ERR_CONNECTION_REFUSED`
2. 同上 38581 端口
3. `SecurityError: Failed to read 'document' from 'Window': Blocked frame with origin "https://crm.hongjian.com" from accessing "https://finance.hongjian.com"`

**反推**:
- **每个模块独立子域**: `crm.hongjian.com` / `finance.hongjian.com` / `main.hongjian.com` / `security.hongjian.com` / `login.hongjian.com` / `resource.hongjian.com` (静态资源 — `jquery.js` 还在用!)
- **iframe 架构**: 每个模块在 iframe 中独立加载, 跨域限制阻止部分通信 (用 `document.domain = "hongjian.com"` 部分桥接但失败案例存在)
- **本地 desktop 助手**: 期待 `localhost.hongjian.com:38580/38581` WebSocket — 推测是**打印机/扫码枪/U盾硬件桥接**, 没装就报错但不影响正常浏览
- **技术栈**: jQuery (老 web 架构) + iframe + JSP

## 4. UX 关键观察 (Phase 1 broad)

| # | 观察 | 对照 Cretas |
|---|---|---|
| 1 | **横向 12 模块顶部菜单** (300+ 子菜单分散于此) | Cretas 用 BentoGrid + BottomTab, **现代得多** |
| 2 | **多 Tab 系统底部** (工作台/流程图/业务) | Cretas Web-Admin 缺! 直接对应 UX_BORROW B-2.W1 (U-WEB-1) |
| 3 | **业务流程图 tab 自动生成** (点击模块就有, 7-14 节点) | 直接对应 UX_BORROW A-1 ⭐⭐⭐ (U-NAV-1), Cretas 完全无 |
| 4 | **Dashboard 12 卡片 + 4×4 常用菜单 + 4×2 最近浏览** | Cretas BentoGrid 是 1×N 分类 (更清爽) |
| 5 | **释放升级日志 in-app feed** (10 条 release notes) | Cretas 没有 in-app changelog (推送/钉钉补?) |
| 6 | **iframe 跨子域架构** (jQuery + JSP 老栈) | Cretas SPA + JWT 现代得多 |
| 7 | **本地 WebSocket desktop 助手** (38580/38581 打印/扫码) | Cretas 用 Expo + 浏览器 API (无依赖) |
| 8 | **3 种登录方式** (账号/手机号/验证码) | Cretas RBAC 角色入口分离, 但只 1 种登录 |
| 9 | **顶部 header "公司名"** 永远显示 | Cretas 没有 — 多租户/多公司支持需要补吗? |
| 10 | **消息计数 (16) badge** + 异常预警 list 对标 AIInsightCard | Cretas AIInsightCard + AIAlertsScreen 已 ship |
| 11 | **3 圆环 chart** (库存成本/银行存款/欠款) | Cretas SmartBI 强于此, 但圆环可视化值得借鉴 |
| 12 | **release notes in-app feed** | 加 `/system/release-notes` 推送给客户 — 客户感知"产品在更新" |
