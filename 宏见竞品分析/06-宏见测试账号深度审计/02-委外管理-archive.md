# 委外管理 — Archive (Tier 3, 浅 audit)

## 入口
顶部菜单 → 委外管理 (12 模块之一)

## 截图
![委外管理子菜单](./screenshots/nav-07-委外管理-fullpage.png)

## 一句话定义
管理跨企业委外加工业务 (B2B 协同) — 我企业作为委托方派工给受托方加工, 或反向接单.

## 主要子菜单 / 功能 (22 项)
- **委托生产** (16 三级):
  - 委托生产 / 委托生产预备 / 库存查询
  - 委外收货列表 / 委托入库列表 / 委托出库列表
  - 委托汇总发料 / 委托批量退货
  - 委托生产申请单 / 委托质检单
  - 委托月结报表 / 委托应付账款
  - 工序委外报表 / 物料需求总表
  - 委外库存盘点 / 委外商价格
- 受托公司列表
- 受托生产
- **在线委托** ⭐ (B2B 跨企业 — Cretas 完全没有)
- **在线受托** ⭐ (反向)
- 参数设置

## 关键字段 (浅看)
推测含: 委托公司编号 / 委托产品 / 工序 / 数量 / 单价 / 发料数量 / 收货数量 / 应付金额

## 跟 Cretas 的潜在关联
Cretas 当前是单工厂模型, 没有委外概念. F006 卤制品工厂自产自销, 不外包. 标 P3 / Archive.

如果未来 Cretas 服务**多分厂集团** (e.g. 餐饮中央厨房 → 多门店), 委外逻辑可参考: 中央厨房委托门店"加工" (其实是配送 + 二次加工).

## 未来场景假设
- 大型电子/机械/服装厂 (大量委外加工 vendor)
- 餐饮集团 (中央厨房 → 多门店"二次加工")
- 食品代工厂 (OEM/ODM 业务)
