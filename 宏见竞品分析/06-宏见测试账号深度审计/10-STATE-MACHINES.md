# 10 — 宏见单据状态机 (≥3 单据完整状态机)

## 1. 销售订单状态机 (4 维度并行)

### 1.1 维度 1: 订单状态 (订单生命周期, 5 状态 + 1 默认)
```
[default: 进行中]
进行中 → 已完成 (终态)
进行中 → 已暂停 ⇄ 进行中 (admin 可恢复)
进行中 → 已中止 (终态)
进行中 + 已完成 (admin 联合查询)
```

### 1.2 维度 2: 出库状态 (14 状态, 按订单 vs 按明细 双轴)
```
未出库 (按订单)
未出库 (按明细)
部分出库 (按订单)
部分出库 (按明细)
完全出库 (按订单)
完全出库 (按明细)
超量出库 (按订单)
超量出库 (按明细)
未出库+部分出库 (按订单)
未出库+部分出库 (按明细)
已出库 (聚合)
出库且退货
建单未出库 (特殊态: 建单后直接关闭, 不实际出库)
```
**14 出库状态** = 7 业务态 × 2 维度 (订单 / 明细)

### 1.3 维度 3: 审核状态 (3 状态)
```
未审核 → 已审核
[default: 不限]
```

### 1.4 维度 4: 收款状态 (8 状态, 含应收维度)
```
未收款 → 部分收款 → 完全收款
未收款+部分收款 (联合)
未收款 (按应收维度)
完全收款 (按应收维度)
未收款 (按应收) + 部分收款
```

### 1.5 完整状态合并 (理论组合 = 5 × 14 × 3 × 8 = 1680 组合)
实际有效组合 ~30:
- 销售订单创建 / 进行中 / 未审核 / 未出库 (新建)
- 进行中 / 已审核 / 未出库 (审核通过等出库)
- 进行中 / 已审核 / 部分出库 / 未收款 (出货中)
- 进行中 / 已审核 / 已出库 / 部分收款 (出完等收款)
- 已完成 / 已审核 / 已出库 / 完全收款 (终态正常)
- 已中止 / 任何 / 任何 / 任何 (异常终态)

## 2. 采购订单状态机 (4 维度并行)

### 2.1 维度 1: 订单状态 (5 状态, 同销售)
进行中 / 已完成 / 已暂停 / 已中止 / 进行中+已完成

### 2.2 维度 2: 收货状态 (7 状态)
```
未收货 → 部分收货 → 完全收货
超量收货 (over 阈值, P-OVER-1)
收货且退货
未收货+部分收货 (联合)
[default: 不限]
```

### 2.3 维度 3: 审核状态 (3 状态)
未审核 / 已审核

### 2.4 维度 4: 付款状态 (5 状态)
未付款 / 部分付款 / 完全付款 / 未付款+部分付款 / [不限]

### 2.5 维度 5: 开票标识 (5 状态)
不收发票 / 未收发票 / 部分收票 / 完全收票 / [不限]

### 2.6 完整状态机 (典型路径)
```
采购底稿 (草稿) → 未审核 → 进行中 / 已审核 / 未收货 / 未付款 / 未收发票
    → 部分收货 → 部分收货 / 已审核 / 部分付款 (如月结)
        → 完全收货 → 完全收货 / 完全付款 / 完全收票
            → 已完成
```

## 3. 库存出库单状态机

### 3.1 维度 1: 出库状态 (3 状态, vs 销售单的 14 状态简化版)
```
未出库 → 已出库
[default: 不限]
```

### 3.2 维度 2: vflag 凭证生成 (4 状态) ⭐⭐⭐
```
[default: 不限]
无需生成 (内部调拨等不入账)
未生成 (待财务批量生成)
已生成 (凭证已 hook)
```

### 3.3 状态联动
```
出库单创建 → 未出库 → vflag = 未生成
    → 实际出库 → 已出库 → vflag = 未生成 (财务 pending)
        → 财务"批量生成凭证" → 已出库 + vflag = 已生成 (终态)
```

## 4. 质检单状态机 (品质模块)

### 4.1 状态 (5 状态, 双维度)
```
[default: 全部]
未质检 → 部分质检 → 已质检
未质检 + 部分质检 (联合, 待处理)
```

### 4.2 检验模式 (2 模式)
全检 / 抽检

### 4.3 完整路径
```
完工 → 未质检 (待检验)
    → 抽检/全检 → 部分质检 (检 N 个完全)
        → 全部检完 → 已质检
            → 良品 / 不良品分流
                → 良品 → 入库
                → 不良品 → 退回 / 报废
```

## 5. BOM 状态机 (工程模块) ⭐⭐⭐

### 5.1 状态
```
BOM 创建 (草稿)
    → 提交审核 → 待审核
        → 批量审核通过 → 已生效 v1
            → 流入: 生产计划 (走 v1 BOM)
        → 退回 → 草稿 (修改后再次提交)
        → ECN 变更 → 新建 ECN 单据
            → ECN 审批通过 → v1 历史化 + 新 v2 生效
                → 旧订单走 v1, 新订单走 v2
            → ECN 拒绝 → v1 继续生效
```

### 5.2 关键: 多版本并存
- 同 BOM 多版本: v1 (历史) + v2 (现行)
- 不是覆盖, 是版本号叠加
- ECN 单据记录变更原因 + 影响范围

## 6. 销售退货单状态机

```
退货单创建 → 待客户确认
    → 客户确认 → 待入库
        → 仓库收回 → 已入库 (库存恢复)
            → 退款执行 → 反向凭证 → 已退款 (终态)
        → 拒收 → 已驳回 (终态)
    → 取消 → 已取消 (终态)
```

## 7. 工作流引擎状态机 (workflow.hongjian.com)

### 7.1 通用 (任何单据走工作流)
```
节点 1 (创建)
    → 提交 (含意见 textarea, default "同意") → 节点 2 (审批人 1)
        → 同意 (意见模板: 设置常用语) → 节点 3 (审批人 2)
            → 同意 → ...
                → 最后节点 (执行/出库/凭证 等)
        → 退回 → 节点 1 (修改)
        → 拒绝 → 已驳回 (终态)
```

### 7.2 关键能力 (推测, 系统管理-工作流设置)
- 多分支 (and / or)
- 并行 (多审批人同时)
- 会签 (全签后通过)
- 条件路由 (金额阈值 / 部门 / 角色)
- 回退 (退回到任一节点)
