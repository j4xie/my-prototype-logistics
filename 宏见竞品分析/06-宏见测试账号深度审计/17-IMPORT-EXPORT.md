## 1. 导入能力 (实测)

### 1.1 Excel 导入 (跨模块)
| 模块 | 入口 | URL |
|---|---|---|
| 销售单 | 销售订单 list 页 → "导入" link | `/saleimport/saleimportlist.jsp` |
| BOM | 工程管理 → "BOM导入" 子菜单 | (推测 `/bom/import`) |
| 客户 | 客户管理 → 数据管理 (推测) | |
| 产品 | 系统管理 → 产品管理 (推测) | |
| 供应商 | 采购管理 → 供应商 (推测) | |
| 员工 | 人力资源 → 员工管理 → 数据管理 (推测) | |

**所有主数据 + 单据**都有 Excel 导入入口 — onboarding 必备.

### 1.2 导入流程 (推测)
1. 下载 Excel 模板 (按模块各自定义列)
2. 填数据 (含必填/格式校验)
3. 上传 → 校验报告 (错误行高亮 + 修改后重传)
4. 确认导入 → 落库

跟 Cretas C-MIGRATE-1 (Onboarding Wizard) 对照. **Cretas 设计 7 步 wizard + 4 模板 + 培训视频**, 比宏见单纯导入更友好 (含培训 + 校验+ 真人验证).

## 2. 导出能力 (实测)

### 2.1 Excel 导出 (跨模块)
| 模块 | 入口 | 范围 |
|---|---|---|
| 销售单 | list 页 → "导出" / "导出列表" | 当前查询条件结果 |
| 采购单 | 同 | |
| 出库单 | 同 + "导出流水" / "导出月报表" (考勤页实测) | |
| 考勤 | "导出流水" + "导出月报表" 两种 | 流水 = 明细; 月报表 = 汇总 |
| 财务 | 报表 → 导出 | 标准报表 |

**特征**: 列表页全部支持当前查询条件下的导出 (按当前筛选范围).

### 2.2 PDF 导出 (实测)
| 模块 | 入口 | 形式 |
|---|---|---|
| 销售单 | 行内 icon "打印销售单" link → `/sale/saleprintselect.jsp?type=sale&id=X&state=none` | 选模板 → 生成 PDF |
| 采购单 | 行内"明细打印" / "打印" button | 同 |
| 凭证 | 财务凭证 → 打印 | 凭证 PDF |
| 考勤 | "打印" button | 月报 PDF |
| 销售合同 | OA 跳转 → 合同打印 | 合同 PDF |

**关键**: 打印走 **系统管理 → 打印管理** 的可视化模板系统 (推测).

### 2.3 批量打印 (实测)
- 销售单 list 页 → 多选 → "批量打印" (推测)
- 采购单同
- 出库单 → "批量生成凭证" + "批量打印" (实测)

## 3. PDF 模板设计能力 (推测)

基于系统管理 → 打印管理 + 销售单"打印销售单"link 实测:
- 模板列表 (按单据类型: 销售/采购/质检/生产/出库/凭证/考勤)
- 每单据可有多模板 (e.g. 销售单可有"标准发货单"/"客户对账单"/"海关报关单")
- 模板编辑器 (拖拽字段 + 字段绑定 + 预览)
- 打印 选模板 弹窗 (saleprintselect.jsp)

类似 Crystal Reports / iText 可视化版.
