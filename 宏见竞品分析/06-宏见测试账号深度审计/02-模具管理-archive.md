# 模具管理 — Archive (Tier 3 子模块, 浅 audit)

## 入口
顶部菜单 → 生产管理 → 模具管理 (生产 31 子菜单之一)

## 一句话定义
管理生产用模具 (注塑模/冲压模/挤压模等) — 档案 + 维修 + 借用 + 寿命追踪.

## 主要功能 (推测)
- 模具档案
  - 模具编号 / 名称 / 类型 / 规格
  - 适用产品 (跟 BOM 关联)
  - 制造商 / 购置日期 / 购置金额
  - 设计寿命 (e.g. 50000 模次) / 当前模次
  - 存放位置 / 当前使用人/工序
  - 状态 (使用中/维修中/报废/库存)
- 模具借用单 (车间间调拨)
- 模具维修记录
- 模次/寿命追踪 (跟工时报表关联)
- 模具更换提醒 (达到 80% 寿命)

## 跟 Cretas 的潜在关联
Cretas 完全没有模具管理. F006 卤制品工厂**不需要模具** (卤制品是煮+包装, 没有注塑/冲压).

模具管理是**特定行业** (注塑/冲压/锻造/印刷/纺织):
- 电子: PCB 模具 / 注塑模
- 汽车: 冲压模 / 锻造模
- 服装: 裁剪模
- 印刷: 印版

## 未来场景假设
- 注塑工厂 (玩具/家电/汽车配件)
- 冲压工厂 (汽车零部件)
- 服装工厂 (鞋楦/裁剪模)

## 跟 Cretas C-DEVICE-LIFE-1 对比
Cretas C-DEVICE-LIFE-1 (设备 6 子模块) 跟模具管理类似但更通用. 模具是**特殊设备子类**.

如果 Cretas 服务模具行业客户:
- C-DEVICE 加 device_type='MOLD'
- 加 mold_count_used / mold_lifecycle 字段
- 加模次扫码记录 (每次使用 +1)
