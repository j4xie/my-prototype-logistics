## 3. linklistarray 跨业务关联 (实测, T3 关键)

采购订单的 `linklistarray` 字段是 JSON, 记录关联 source:
```json
[
  {"LINK_TYPE": "sale", "LINK_NO": "00000060"},   // 销售单触发
  {"LINK_TYPE": "produce", "LINK_NO": "P0001"}    // 生产单触发
]
```

**8 种 LINK_TYPE 枚举**:
- sale (销售单)
- sample (样品单)
- request (请购单)
- produce (生产单)
- outsource (委外单)
- stock (备货单)
- project (项目)
- (free / 自由采购, 无关联)

**应用**:
- 反查"哪些销售单触发了这个采购单" — `WHERE LINK_TYPE='sale' AND LINK_NO=?`
- 反查"哪些采购单是为生产单服务" — 反向追溯
- **Cretas 当前 S-MRP-1 是单向 (销售→采购), 缺反向追溯能力**

## 4. 备货 / 锁定 / 缺料 (实测, T1 核心)

销售单行内显示:
```
[Z14736842]密封压盖  锁:0  备:1  缺:0
```

| 字段 | 含义 | 公式 (实测 tooltip) |
|---|---|---|
| 锁:N | 已锁定库存 | (admin 手动锁定 / 销售审批自动) |
| 备:N | 已转其他单备货中 | (生产/采购单已生成在备) |
| 缺:N | 缺口数量 | **未出库 - 锁定 - 备货** ⭐ 公式实测 |

**自动联动**:
- 销售单审批通过 → 锁定库存 (锁 +N)
- 缺料 (缺 > 0) → 自动触发缺料分析 (S-MRP-1) → 请购/转生产
- 转生产建立 → 备货中 (备 +N)
- 备货完成 → 备 → 锁
- 出货 → 锁 → 0 (完成)

**Cretas 对应**:
- ✅ MaterialBatch 已有库存
- ❌ 缺"锁定 / 备货中 / 缺口"3 维度细分 + 公式
- ❌ MUST_COPY 增量 P1: 行内显示 锁:N 备:N 缺:N + 工时 1d

## 5. 三价对比触发 (T5 — P-3PC-1 已 ship)

## 7. 月底自动 (T12)

期间结账 (月结对帐 + 结账管理 子菜单):
- 月底自动: 工资生成 → 月结对账单 → 期间凭证检查 → 锁定期间
- 锁定后: 不能修改本期间任何单据 / 凭证
- 跨期: 走调整凭证 (反向 + 当期重做)

Cretas 完全缺, P3 (大客户场景才需).

## 8. AI 触发 vs 单据触发对照

| 触发模式 | 宏见 | Cretas |
|---|---|---|
| **单据驱动** (传统) | ✅ 主流 (12 种联动) | 部分 (基础 trigger) |
| **AI 驱动** (创新) | 缺 | ✅ AIChat 一句话跨多步 (Skill 编排) |

**互补建议**:
- Cretas 加单据驱动联动作为底层 (T1-T12 补齐)
- AIChat 仍然是上层入口, 内部仍然走单据 trigger
- → "AI 输入 + 单据输出" 双通道
