# 邮件正文

各位领导:

非常感谢六扇门团队过去 8 周的耐心配合与详尽反馈。前后 4 次会议下来,你们提出的全部 P0 问题已经在生产环境逐一修复并通过验证,同时我们额外补齐了 4 项你们日常一定会用到的新能力。系统已经可以从**研发样品 → 销售下单 → 缺料分流 → 生产排程 → 工序报工 → 调拨入库 → 销售出库 → 开票收款**整条主流程跑通。现把交付情况、试用账号、培训资源一并送上,请审阅。

## 一、本次修复的 10 个 P0 问题(均已上线生产)

1. **生产计划工序下拉只显示"通用"** — 现在已能正确带出该产品已配置的工序流(例:猪蹄 → 拆包 → 分割 → 卤制 → 抛骨 → 分切 → 装盒 → 装筐)。
2. **新建销售订单弹窗太小看不到字段** — 弹窗宽度自适应,所有字段一屏可见。
3. **BOM 配方原辅料只能手写** — 改为关联仓库原料字典下拉选取,物料编码、单位自动带出。
4. **调拨单看不到现有库存** — 调拨单列表加列"现有库存",发运前直接可见,无需切到库存页核对。
5. **缺手动调拨入口** — 仓库手动新建调拨单入口已开放,适用领用、研发用料等无销售订单场景。
6. **生产任务"开始"按钮不校验库存** — 已加库存校验,原辅料不足时弹出提示,杜绝虚拟开工。
7. **调拨单不能选批次** — 发货可手动选批次,默认 FEFO 最早批次,做原切等对货期有要求场景可手动覆盖。
8. **缺分仓库存查询页** — 已上线,总仓 / 工厂线边仓实时分账。
9. **工厂出库逻辑** — 已按"工厂=线边仓"原则修正:原料从总仓调入,生产剩余按"虚拟出库"调回总仓,成品按整批调到总仓再发货。
10. **销售出货逻辑** — 已固定走总仓,工厂只生产不发货,与你们实际操作流程一致。

## 二、本次新增的 4 项能力(超出原会议要求)

1. **通用附件系统** — 销售订单、采购订单、入库单、质检、财务凭证全部支持拍照留档,完整满足"双方签字 + 拍照 + 留附件"入库闭环。仓管员手机直接拍传即可。
2. **工厂端 BOM 配方编辑 UI** — 输入 200g 成品 + 58% 出成率,系统自动折算 250.58g 原料需求;克 ↔ 千克 1:1000 后台自动换算,调拨单按公斤自动给到仓库,无需人工换算。
3. **抄码品识别** — 原料字典加"抄码"标记(适用牛肉等每箱重量不一的原料),采购时不再要求填箱数,改为入库实际称重验码,入库数据更准。
4. **钉钉机器人接入** — 你们日常用钉钉的同事,可直接在群里发"昨天产了多少猪蹄"、"鸡爪库存还有多少"得到回复;系统检测到异常(库存告警 / 三价偏离 / 质检不合格等)会主动推送到指定钉钉群,无需登录系统页面。
