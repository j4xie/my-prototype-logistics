## C. UI 设计模式

### C1. 顶部累积 Tab Bar (sticky)
每打开一个 sidebar 项, 横向加一个 close-tab. 帧 000208 已有 8 tab (工作台/流程图/生产任务管理/销售产品需求表/物料需求/请购汇总/请购单/销售订单). 帧 001038/001134 累积到 16+ tab. **无 tab 折叠/聚合机制** — UX 退化, tab bar 会被挤爆.

### C2. 二级 Tab Bar (sub-tab)
切换 sidebar 主项后, 内部还会出现第二条 tab bar. 例如客户管理(001134) 主 tab 16 个, 下层"客户价格 | 客户查询(按手机)" 子 tab. 看起来 sub-tab 是模块切换的次序痕迹.

### C3. 行级颜色块状态徽章
全系列单据都用 **左上角色块标识** (粉/紫/蓝/绿/灰), 配 中文文字 (正常生产/准备中/已审核/已收货/未质检/正常补录/旷工 等). 销售退货 (001215) 颜色标识: 未入库/已入库. 销售订单 (001149): 未出库/部分出库/已出库/超量出库. 采购订单 (000338): 未收货/部分收货/完全收货/超量收货.

### C4. 底部批量操作工具栏
表格底部 sticky 批量条 (含 行选数提示). 销售单需求 (001152): "已选0条 | 转请购 | 转采购 | 转生产 | 转委外申请 | 转预备 | 转外购 | 可用库存". 销售退货入库 (001215): "批量操作". 物料需求 (000325): "选中2条 | 锁定库存 | 生成请购订单 | 生成采购订单 | 批量转生产 | 批量转委外 | 批量转委外申请".

### C5. 行级"操作"下拉菜单
每行右侧 操作▼ 按钮, 展开 6-15 个操作. 例如 生产任务行 (000545) 展开 16 项: 物料 / 工序流转 / 成品入库 / 成品入库(不良) / 成品返工 / 调拨线边仓 / 生产领料 / 生产补料 / 余料退回 / 废料退回 / 其他领料 / 其他退料 / 边胞入入库 / 工艺打印 / 任务删除. 角色管理行 (001604) 展开 8 项: 功能权限设置 / 数据权限设置 / 打印权限设置 / 第三方权限设置 / 员工 / 复制 / 删除 / 修改. 工序流转 (000836) 8 项: 完工/完工列表 / 质检列表 / 返工/返工列表 / 流程修改 / 在制品入库/在制品出库 / 在制品调入/在制品调出 / 工序委外 / 工艺描述/作业指导书 / 工艺打印.

### C6. 二维码弹窗 + 扫码动作
帧 000553, 000809: 生产任务行点击 操作 → "App扫描查看订单" 弹窗显示 二维码. 客户用手机扫码后即可执行报工/入库/领料. 是手机端 + PC 端混合工作流的核心入口.

### C7. 流程图 (Mermaid-like 卡片图)
- 采购流程图 (001722): 销售订单 → 请购单 → 采购底稿 → 询价单 → 采购订单 → 采购变更单, 旁支 核价单 (yellow). 采购订单 → 质检单 → 采购入库 → 报表; 采购退货 ← 采购入库.
- 品质流程图 (001311): 收料单 → 进货检验单 → 报表; 检验退回单; 委外收料单 → 委外检验单 → 委外检验退回单; 生产入库检验单; 库存检验单
- 人力资源流程图 (000929): 9 个 boxes 网格 (考勤 / 工资 / 劳务合同; 员工管理 / 离职花名册 / 绩效管理; 加班 / 请假 / 招聘)
- 工作流流程图 (000443): 销售订单 → 销售出库, 销售订单审核 (分流箭头)

模块导航的另一种方式: 流程图卡片 = visual sidebar, 点击 box 进入对应单据列表. 同一模块同时支持 sidebar 列表 和 流程图卡片 两种 UI.

### C8. 多产品分类左侧树 (产品筛选)
帧 000114, 000208, 001152: 销售产品需求表左侧树 "所有 > 成品 > IV类产品/I类产品/II类产品/III类产品 ; 半成品 ; 物料". 是产品分类的二级树, 与列表配合做下钻筛选.

### C9. 表单复杂度
- 生产领料单创建 (000745, 000754) — 顶部 6 fields (任务编号/工序/仓库/领料方式/车间/物料申请人员/申请部门/业务日期) + 子 tab (汇总发料/工序发料) + checkbox (库存不足按勾选库存数量/按勾选进行领料) + 表格 19 列 (序号/图片/品牌/物料编码/物料名称/规格/属性/BOM单个用量/计划数/申请数/补料数/余料退数/废料退数/实领数/单位/当前库存/申请数量/备注/操作)
- 客户详情 (001052) — 5 个 collapsible sections (订单属性 9 字段 / 客户属性 5 字段 / 系统信息 6 字段 / 自定义信息 5 字段) + 16 tab bar + 跟进历史 grid + 6 个 footer 按钮 (返回/保存/保存并关闭/更多/已成交/操作). **过载严重**.

### C10. 权限树多级 checkbox
帧 001628, 001641 角色管理 → 功能权限设置 弹窗. 多层折叠 checkbox (Tree control). 顶层 30+ 模块, 每个展开 5-20 子项. 例如 实用工具 → 查看知识库/记事本/事件提醒/通讯录/课程表/抽奖管理. 工作流 → 待处理工作流/我创建的工作流/我参与的工作流. 整个树估算 200+ checkbox. **粒度极细但难以管理**.

### C11. Status pill 与文字混排
状态显示是色块 + 文字, 例如"正常生产"/"准备中"/"默认车间"/"已领0%"/"工二". 整张行充斥短状态字符串, 不像现代 UI 用 icon/紧凑标签. 信息密度高但可读性低.

### C12. 多账户多币种 (财务模块)
帧 001541: 顶部账户切换 tabs (AA(¥) / SA4111($) / 建行2651(¥) / 工行4112(CNY)(¥) / 银行本票存款(CNY)(¥)) — 同时支持人民币 ¥ 和美元 $, 多账户独立账本.

### C13. 子站点跳转 (微服务边界)
- 主站 `main.hongjian.com` (12 模块 ERP)
- 仓库子站 `stock.hongjian.com` (库存详细钻取, 例如 [CP001] 进出库流水 001426)
- 客服子站 `mobile.hongjian.com/客服50` (工作手机 CRM, WeChat 集成, 002227)

子站点之间从主站点可以跳转, 但是 UI 风格略有差异 (子站点更轻量, 没有顶部 12 模块 tab bar).

## D. 工作流证据

### D1. 二次处理 = 单据状态转换的核心动词
销售订单 → 转生产 / 转外购 / 转委外 / 转请购 / 转采购 (销售产品需求表批量条 + 行级下拉)
请购单 → 转采购订单 (采购管理工作流)
生产任务 → 工序流转, 成品入库, 成品入库(不良), 成品返工, 调拨线边仓, 生产领料, 生产补料, 余料退回, 废料退回 (生产任务行操作下拉)

### D2. 审批链 = 工作流引擎
生产领料单创建页 (000745) 顶部显示 "审批历史 | 生产领料 | 当前节点: 生产领料单创建", 意见 + 同意 + 提交按钮. 这是 BPM-style 审批节点视图. 工作流可在系统管理 > 工作流 sidebar 配置 (000312).

### D3. 跨模块衔接 (销售→生产→采购→仓库→财务)
销售订单创建 → 销售单 (列表 001149) → 销售产品需求表 (001152, 转生产/转外购) → 生产任务管理 (000010) → 物料需求按工序 (000325, 锁定库存/生成请购/生成采购) → 请购单 (000411) → 请购汇总 → 采购订单 (000338) → 采购收货单 (001521, 已质检/未质检) → 采购入库 → 库存查询 (001353) ← 生产领料单 (000745) → 工序流转 (000836) → 成品入库 → 销售出库 → 财务凭证 / 应收应付.

### D4. 工序流转支持 standard mode
帧 000836: "生产编号: SC260422-001 测试成品A1 的工序流转 (标准模式)". 显示 列出 "组装 200PCS / 包装" 两个工序节点, 每节点显示 计划数量/待流入/流入/安排/完工/待质检/质检信息/完成比例(20%)/不合格/流出/委外/总工时. 标准模式说明还支持其他模式 (高级模式? 精简模式?).

### D5. 报工 (生产计件)
帧 000745, 001003: 二维码扫码 (000553) 是报工的入口. 工人扫码后可记录: 计件数量/工时. 分两种模式: ①个人扫码报工 (具体到人) ②组长批量录入 (用 PC 上的 批量新增 功能, 在 PC 上勾选人员+填数量).

### D6. 多收款方式合同 (财务衔接)
销售订单 (001149, 001215) 显示行级"月结1"/"现金"/"应付:56-0-0=56 发票:56-0-56"等公式. 表示销售订单支持: 应付计算 (订单金额 - 已付 - 应付折让 = 净应付), 月结/即时/分次三种结算方式.

### D7. 货品出入库 FIFO + 批次
依据描述 (storyboard 001345-001353 段): 仓库支持 FIFO 默认成本 + 按指定批次出货 (用户可以在领料单上选批次), 包含: 多仓库 / 多仓位 / 多批号 / 不同供应商批次 / 不同生产日期 / 不同销售失效期. 制效天数预警 (产品失效期预警).

### D8. 第三方设备集成
设备管理 (001918) 显示电表/三色灯 column — 表明系统集成 IoT (MES/SCADA 类). 接通考勤机 (人力资源描述 001551), 也是 IoT.

## E. 客户决策段画面 (17:00-22:30)

## 总结性观察

**产品深度**: 宏见 ERP 是 **mature B2B ERP**, ~280+ 功能模块, BPM 工作流引擎, RBAC 多级权限, IoT 集成, 多币种财务, 跨子站点架构. 制造业 MES 级深度 (工序流转 / 报工 / 设备点检).

**产品劣势**:
- UI 信息过载 (tab bar 累积, 表格 19 列, 状态徽章一行 8 个)
- 行业 demo 数据偏机械加工, 不利于其他行业演示
- 高级功能 (核价单 / 询价单 / 工序备料 / 委外检验) 强制曝露给所有客户, 没有渐进式发现

**销售流程问题** (这次苏州/昆山食品厂案例):
- 售前没有行业适配判断, 全程用机械加工 demo
- 售前主动承认有"冗余功能可去掉", 反向暗示产品不专业
- 设备管理 stuck 5 分钟, 没意识到客户行业不匹配
- 死守"授权线下"流程, 阻断了客户的在线试用请求
- 没有 ROI / 价格预算 / 实施周期 的具体承诺

**该客户极大概率不会签约** — 客户最后的 "好, 可以没问题. 因为那个是." 是礼貌结束, 实际是放弃信号. 售前没有捕捉到这个信号, 仍在 客服 CRM 子站演示 "邀约上门快捷语".
