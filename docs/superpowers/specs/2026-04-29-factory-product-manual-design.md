## 1. 背景

工厂版操作手册当前文件 `docs/plans/factory-operation-manual.html`：
- 7236 行，20 章，已入库 KB 287 chunks（subcategory='factory'）
- 风格偏 dev/QA 流程式（"Step 7.1: 进入生产计划页面" → 1) 打开 → 2) 左侧菜单...）
- 详细描述了按钮名、字段、菜单路径，对工厂内部 onboarding 价值很高

但 vs 已上线的餐饮版手册（24 章 + 4 培训路径 + 6 决策合成）：
- 没有"概述/入门怎么用/管理怎么解读/FAQ"产品手册式结构
- 没有培训路径
- 没有决策合成（跨章节场景）
- 章节模板不统一

目标：把工厂手册重组到跟餐饮版同一水平，**保留现有 Step 详细内容作为深度参考**，章节头加产品手册式结构，让客户（厂长、班组长、操作工）也能用，而不只是 QA 内部用。

## 4. §0A AI Query 章节内容设计

### 4.1 概述（200-300 字）

智能数据分析 (AI Query) 是白垩纪 SaaS 的核心分析入口，允许工厂用户用自然语言直接提问，例如"本月哪条产线 OEE 最低？"或"上周哪个 SKU 损耗率最高？"，无需编写 SQL 或配置 BI 报表。系统自动识别字段、执行聚合、生成图表并输出文字解读。适合厂长、生产主管、品控经理等管理岗位日常监控经营数据，让前线班组长也能独立获取数据洞察，无需依赖 IT 配置。

### 4.2 §0A.1 进入路径（2 条）

1. **菜单路径**：登录 Web Admin → 左侧"智能 BI"分组 → "智能数据分析"
2. **Dashboard 快捷入口**：首页"快捷分析"卡片 → 点击预设场景按钮（如"今日产量"、"本周良品率"）

### 4.3 §0A.2 主界面 layout（4 区块）

| 区块 | 位置 | 功能 |
|------|------|------|
| 顶部工具栏 | 页面顶部 | 数据集选择、上传 Excel、历史对话 |
| 中央查询输入区 | 页面中部 | 自然语言输入框 + 快捷问题按钮 |
| 结果展示区 | 输入区下方 | AI 回答 + 图表（柱/线/饼） |
| 左侧历史面板 | 页面左侧 | 历史问答列表（按时间倒序） |

### 4.4 §0A.3 常用操作步骤（8 步）

仿餐饮版结构，但替换工厂示例：
- 选择/上传数据集（生产报工、质检、设备运行数据）
- 输入问题（"本周哪条产线 OEE 最低？"）
- 查看回答 + 图表
- 追问（"该产线主要停机原因是什么？"）
- 导出结果（PNG / CSV）

### 4.5 §0A.4 常见错误处理（5+ 行）

仿餐饮版结构，针对工厂场景：
- "字段未识别" → 检查 Excel 列名是否清晰（"产线号"而非"line"）
- "回答与预期不符" → 加具体维度（产线号、SKU、班次）
- "数据集为空" → 联系系统管理员开通权限

### 4.6 §0A.5 关键指标速查（厂长视角）

| 指标 | 计算口径 | 健康区间 | 红线 |
|------|----------|----------|------|
| OEE (设备综合效率) | 可用率 × 性能率 × 良品率 | 70-85% | <60% 红线 |
| 良品率 | 合格件 / 投产件 | 95-99% | <93% 红线 |
| 工序合格率 | 合格批次 / 总批次 | 98%+ | <95% 红线 |
| 损耗率 | 实际用料 / 标准用料 - 1 | <5% | >10% 红线 |
| 设备利用率 | 实际运行时间 / 计划时间 | 75-90% | <60% 红线 |
| 人均产值 | 营收 / 在线工人数 | 行业基准 | 季度对标 |

### 4.7 §0A.6 业务判断框架

3 个常见诊断场景：
- **OEE 突然下滑** → 拆 可用率 / 性能率 / 良品率 → 定位是停机、慢车、还是质量问题
- **损耗率超标** → 看 SKU 维度 → 查 BOM 配方 vs 实际领料 → 转 §5 / §10
- **某产线良品率低** → 看工序维度 → 查质检记录 → 转 §6F / §15

### 4.8 §0A.7 跨章节联动

5 行：链到 §13 SmartBI / §11 报表 / §14 财务 / §10 报工 / §6F 质检

## 5. §0B 财务 PBI 看板章节内容设计

### 5.1 概述（200-300 字）

财务 PBI 看板是白垩纪 SaaS 的标准财务可视化入口，自动从生产报工、采购入库、销售出货、人工工资等系统数据汇总成月度损益、成本结构、应收应付、现金流四大视图。无需会计手工整理，看板自动按月聚合，支持多工厂切换、按 SKU/客户/产线下钻，让厂长和财务文员快速识别成本异常、回款风险和利润趋势。

### 5.2 §0B.1 进入路径（1 条）

菜单路径：Web Admin → "财务管理" → "财务 PBI"

### 5.3 §0B.2 主界面 layout（5 区块）

- 顶部时间筛选器（月/季/年）
- 4 大卡片：营收 / 成本 / 利润 / 现金流
- 中部图表：损益瀑布图、成本桑基图
- 左侧导航：损益表 / 应收账龄 / 应付清单 / 成本分析
- 右侧 AI 洞察面板（自动生成本期重点提示）

### 5.4 §0B.3 常用操作步骤（5 步）

- 选时间范围
- 选工厂
- 看 4 大卡片汇总
- 下钻图表（点柱状图某月跳到该月明细）
- 导出 PDF / Excel

### 5.5 §0B.4 常见错误处理（5 行）

### 5.6 §0B.5 关键指标速查

| 指标 | 计算 | 健康区间 |
|------|------|----------|
| 毛利率 | (营收 - 直接成本) / 营收 | 食品加工 25-35% |
| 营业利润率 | 营业利润 / 营收 | 8-15% |
| 应收账龄 | 30/60/90/90+ 天分布 | 90+ <10% |
| 现金流 | 经营 / 投资 / 筹资 | 经营为正 |
| 单位成本 | 总成本 / 产量 | 工厂自定 |

### 5.7 §0B.6 业务判断框架

3 个场景：毛利率下滑 / 应收恶化 / 现金流转负

### 5.8 §0B.7 跨章节联动

## 9. 风险与回滚

**风险 1**：§0A 内容跟现有 §12 (AI 对话 + 常见问题) 重复
- 缓解：§0A 是 BI 分析视角，§12 是 LLM 助手视角，定位区分清晰；§0A 概述里点明"详见 §12 AI 对话"

- 缓解：先 dry-run（只 print 不写库），确认章节切分合理后再真入库；保留入库前 chunks count 作为回滚基准

**风险 3**：Tier 1 章节模板不够工厂化（直接复制餐饮版导致工厂用户违和）
- 缓解：例子都用工厂场景（OEE/产线/SKU/批次），不是餐厅场景（翻台/客单价）

回滚：
- 文件：`git revert`
