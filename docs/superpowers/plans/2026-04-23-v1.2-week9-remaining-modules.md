- [ ] **Step 1: Read sales/orders/list.vue to locate mount point**

Find the top of the template's content area (after breadcrumb, before the orders filter bar).

- [ ] **Step 2: Add script state (ref + fetch)**

```typescript
import { getFinanceSummary, type FinanceSummary } from '@/api/smartbi/gold';

const goldSummary = ref<FinanceSummary | null>(null);

async function loadGoldSummary() {
  if (!factoryId.value) return;
  // Default to YTD; extend to accept the filter bar's date range later.
  const end = new Date().toISOString().slice(0, 10);
  const start = `${new Date().getFullYear()}-01-01`;
  try {
    const r = await getFinanceSummary({
      factoryId: factoryId.value,
      startDate: start,
      endDate: end,
      topNStores: 3,
    });
    goldSummary.value = r && r.billCount > 0 ? r : null;
  } catch {
    goldSummary.value = null;
  }
}
```

Call `loadGoldSummary()` from existing `onMounted`.
