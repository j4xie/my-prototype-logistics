## R72-FIX-B Probe Design

Bypass JWT path interceptor via body-level cross-factory smuggling:

| Layer | Check |
|---|---|
| **Layer 1 (JWT path interceptor)** | path factoryId vs token factoryId — ALLOWS `F001 token + /api/mobile/F001/...` |
| **Layer 2 (service-level R68-FIX-B)** | request body's equipmentId resolves to Equipment.factoryId — REJECTS if Equipment.factoryId != path factoryId |

Probe:
```
F001 token + POST /api/mobile/F001/equipment-alerts
body: { equipmentId: 5 (F002 equipment), alertType, level, message }
Expected: HTTP 403 + R68-FIX-B specific message + actionHint
```
