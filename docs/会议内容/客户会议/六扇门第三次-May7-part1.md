## 关键客户诉求摘要

> 注: Whisper 语音识别有少量错字 (例如 "超码" 实际是行业术语 "**抄码**", "省批" = "**审批**", "助体" = "**主体**"/原料, "云南" = "**订单**", "相归" = "**箱规**"/规格)

### 1. 箱数自动算 (主诉求 — 已部分实现)

- 客户原话: "我下了一个是1000公斤的主体, 那我就是100箱" — 按规格折算
- "一级单位和二级单位的转换系数, 这个在原料字典里面可以加一个" — 系数维护点
- 当前系统状态: 已有箱数字段, 但 UI 字太小 "字太小了挡住了"
- **现 PR 关联**: PR #173 P1 batch (餐饮 P1 — 超收/预估成本/箱数/抄码) — 箱数自动计算已落地

### 2. 抄码品 (Abaca) 特殊情况识别

- 客户原话: "有些规格他其实是抄码的, 每箱的规格是不一样的"
- "比如说像牛肉, 他每箱的重量都不一样, 所以你没法根据规格去计算"
- 期望行为: 规格写"抄码" → 采购单箱数字段**不显示**箱数 (因为每箱重量动态)
- 验码时机: "入库的时候做" (不是采购单创建时)
- **现 PR 关联**: PR #173 P1-3 (抄码品识别 spec exact match `=== '抄码'` 含 trim, 不用 `includes` 避免误报)
- **memory 锚点**: `reference_abaca_term.md` — Whisper 易转写为"超码", 标记规则已 spec 化

### 3. 三价对比分析 (Self-confirm)

- 客户提问: "这边不是有一个三价对比分析吗, 这个是自动生成的还是什么"
- 系统答: "是自动生成的, 根据以往的采购价会生成的, 近期价那个价格"
- 客户预期已满足: "因为现在没有其他内容, 然后他就可能就只有一个当前采购价, 其他是旧的" → 行
- **现 PR 关联**: 已实装 (具体 PR 待 grep)

### 4. 预计到货时间 (字段命名 confusion)

- 客户原话: "加一个那个预计到货时间, 在采购订单创建的时候加"
- 系统答: "有一个**期望交货时间**" — 客户认可 "差不多这个意思"
- **行动项**: 字段已存在, 名为 "期望交货时间" — 可考虑客户口径 alias 为 "预计到货时间" (UX 词典统一)

### 5. 工作流 / 审批链配置

- 客户问: "工作流是在哪设置的"
- 系统答: 现在审批链需专门配置, 角色生成账号后默认管理员审批; 后续按职位/人数动态调整
- **状态**: 配置入口在管理后台, 业务流先跑通后再细化审批链

### 6. UI 列宽 / 字段挤压

- 客户原话 ×2: "字太小了挡住了" + "盒子什么板子都摆不对"
- 现象: 采购单详情页箱数字段被截断, 创建单子时数字栏挤压
- **现 PR 关联**: 列宽问题历史 feedback `feedback_ui_smoke_scope_creep_default_ticket.md` 提到 PR #126 是历史列宽 fix 的代表性 PR
- **建议**: file UI ticket — 采购单详情页列宽 audit
