设备管理 (Equipment Management)

工厂管理员 Web Admin

设备管理模块覆盖工厂全部设备的台账管理、维护记录跟踪和告警监控。通过设备状态一目了然地掌握每台设备的运行情况，并在设备异常时第一时间收到告警通知。

设备列表

设备管理 › 设备列表
菜单路径: 设备管理 → 设备列表 (/equipment/list)

设备列表页展示当前工厂全部设备的台账信息。页面顶部有搜索栏和筛选条件，列表以卡片或表格形式展示每台设备。

用户看到什么

1
设备卡片 / 表格列表
每台设备显示：设备名称、设备编号、设备类型、所属车间/产线，以及当前状态标签。
2
状态指示器
每台设备有彩色状态标签： 运行中 / 待维护 / 故障停机 / 已停用。 可通过状态筛选快速定位需要关注的设备。
3
搜索与筛选
支持按设备名称、编号关键词搜索，按设备类型和状态下拉筛选。

关键操作

1
新增设备
点击右上角「新增设备」按钮，填写设备名称、编号、类型、所属车间、购买日期、使用寿命等信息后提交。
2
编辑 / 查看详情
点击设备行的「编辑」按钮修改信息，或点击设备名称查看完整详情页（包含维护历史、告警记录等）。
3
停用 / 启用设备
对已报废或暂不使用的设备可点击「停用」，停用后不再参与维护提醒和告警统计。
建议 设备编号建议采用统一格式（如 EQ-001、EQ-002），便于后续维护记录和告警关联查询。设备类型建议提前规划好分类（如：分切机、包装机、冷冻设备等）。

维护记录

设备管理 › 维护记录
菜单路径: 设备管理 → 维护记录 (/equipment/maintenance)

维护记录页面管理所有设备的保养和维修历史。支持按设备筛选查看维护历史，并可创建新的维护记录。

用户看到什么

1
维护记录列表
列表按时间倒序展示全部维护记录。每条记录包含：设备名称、维护类型（日常保养/故障维修/定期检修）、维护日期、维护人员、维护内容摘要、状态。
2
维护计划提醒
系统根据设备的上次维护日期和维护周期，自动提示即将到期的设备维护。到期设备行会显示黄色高亮提醒。

关键操作

1
新建维护记录
点击「新建维护记录」按钮。选择设备（下拉搜索）、维护类型、维护日期、填写维护内容描述，点击确定提交。
2
按设备筛选
页面顶部「设备」下拉框可筛选某台设备的全部维护历史，方便查看单台设备的保养记录。
3
导出维护报表
点击「导出」按钮将维护记录导出为 Excel 文件，用于归档或提交给设备供应商。
维护类型说明 日常保养：常规清洁、润滑、检查，频率较高（每日/每周）。
定期检修：按维护周期（月度/季度）进行的系统性检修。
故障维修：设备异常停机后的紧急维修，需记录故障原因和处理方案。

设备告警

设备管理 › 告警管理
菜单路径: 设备管理 → 告警管理 (/equipment/alerts)

告警管理页面汇总展示所有设备的告警事件。告警来源包括：传感器异常、维护超期、手动上报等。

用户看到什么

1
告警列表
列表展示所有告警事件，每条包含：告警时间、设备名称、告警类型、严重级别（高/中/低）、告警内容、当前状态（待处理/已确认/已解决）。
2
严重级别颜色标识
高 红色背景 — 需立即处理（如设备停机、安全隐患）； 中 橙色 — 需当日关注（如温度偏高）； 低 蓝色 — 信息提醒（如维护到期提醒）。

关键操作

1
确认告警
对于未处理的告警，点击操作列的「确认」按钮表示已知悉并开始处理。确认后告警状态变为「已确认」。
2
解决告警
处理完毕后点击「解决」按钮，填写处理说明（可选），状态变为「已解决」。
3
筛选与排序
支持按严重级别、状态（待处理/已确认/已解决）、设备名称筛选。默认按时间倒序排列，「待处理」的高级别告警置顶。
注意 高级别告警需及时确认和处理。如果一条告警长时间（超过 24 小时）处于「待处理」状态，系统会在首页 Dashboard 和 App 端推送提醒。

数据分析 (Analytics)

工厂管理员 Web Admin 分析模块主要面向管理层和调度员使用

数据分析模块提供多维度的生产运营数据可视化，包括生产 KPI、人效分析、趋势图表、进销存闭环等。帮助管理者快速把握工厂运营状态并发现问题。

生产数据分析

生产分析 › 生产数据分析
菜单路径: 生产分析 → 生产数据分析 (/production-analytics/production)

生产数据分析页面集中展示工厂的核心生产指标，支持按时间范围和产线维度切换查看。

用户看到什么

1
核心 KPI 卡片
页面顶部展示关键数据卡片：当日/本周/本月产量、计划完成率、良品率、设备稼动率。每个卡片带环比变化箭头（涨/跌）。
2
产量趋势图
折线图展示选定时间段内的每日产量趋势，支持按产线叠加展示。可切换日/周/月粒度。
3
产线对比柱状图
柱状图横向对比各产线的产量、良品率等指标，直观展示哪条产线表现更优。
4
时间范围选择器
页面顶部提供快捷按钮（今天/本周/本月/自定义），切换后所有图表和 KPI 卡片同步刷新。
数据来源 生产数据分析的数据来自员工报工记录和生产批次表。确保车间员工正常签到、报工、签退后，数据才会完整呈现。

人效分析

生产分析 › 人效分析
菜单路径: 生产分析 → 人效分析 (/production-analytics/efficiency)

人效分析页面从劳动效率角度分析各产线和员工的生产效率，帮助发现效率瓶颈和优秀员工。

用户看到什么

1
人效 KPI 概览
人均产量、人均工时、单位人工成本等核心人效指标。
2
员工效率排名
表格列出各员工在选定时段内的产量、工时、人均产出，支持按指标排序。
3
产线人效对比
横向对比各产线的人员配置和产出效率，用于评估产线人力分配是否合理。
计算口径 人均产量 = 总产量 / 参与人数。工时数据来自员工签到签退记录。若员工忘记签退，工时数据可能不准确，建议管理员定期检查考勤记录。

KPI 看板

数据分析 › KPI 看板
菜单路径: 数据分析 → KPI 看板 (/analytics/kpi)

KPI 看板以仪表盘形式一屏展示工厂最核心的运营指标，适合大屏投放或管理层每日查看。

用户看到什么

1
核心仪表盘
多个 KPI 卡片以网格布局展示：日产量、良品率、订单完成率、设备稼动率、库存周转天数、人均产出等。每个 KPI 带颜色编码（绿/黄/红表示达标/临界/告警）。
2
环比/同比变化
每个 KPI 指标下方显示与上一周期的对比变化（箭头 + 百分比），快速判断趋势方向。
3
自动刷新
看板数据默认每 5 分钟自动刷新一次，也可手动点击右上角刷新按钮立即更新。

趋势分析

数据分析 › 趋势分析
菜单路径: 数据分析 → 趋势分析 (/analytics/trends)

趋势分析页面提供可配置的多指标时间序列图表，用于发现长期运营趋势和周期性规律。

用户看到什么

1
多指标折线图
支持同时选择多个指标在一张图上叠加展示（如产量 + 良品率 + 订单量），使用双 Y 轴适配不同量纲。
2
时间粒度切换
支持日/周/月三种时间粒度。月粒度适合查看季节性趋势，日粒度适合排查具体问题。
3
指标选择器
左侧或顶部的指标勾选面板可勾选/取消感兴趣的指标类别（生产、质量、仓储、财务等），图表实时更新。
建议用法 周报/月报时使用趋势分析页面，选择过去 4 周或 3 个月的数据，对比产量和良品率的变化。如果发现良品率持续下降，结合质检记录查找原因。

进销存闭环总览

数据分析 › 进销存闭环总览
菜单路径: 数据分析 → 进销存闭环总览 (/analytics/supply-chain)

进销存闭环总览是一张全局视图，将采购（进）、生产+仓储（存）、销售+出货（销）三大环节串联起来，帮助管理者看清全链路的物料和资金流动。

用户看到什么

1
三大环节概览卡片
页面顶部三个大卡片分别展示：采购金额/数量汇总、当前库存价值/周转天数、销售金额/出货量汇总。
2
流转示意图
以桑基图或流程图形式展示物料从采购入库到生产消耗再到成品出库的流转路径和数量比例。
3
异常预警
当出现库存积压（周转天数过长）、采购与消耗不匹配等情况时，页面会以红色/橙色标注提醒。
闭环逻辑 进销存闭环的核心是确保：采购量 ≈ 生产消耗量 + 安全库存调整，销售量 ≈ 生产产出量。如果两侧数据长期偏差过大，说明供应链存在浪费或短缺风险。

调度管理 (Scheduling)

工厂管理员 / 调度员 Web Admin

智能调度模块提供可视化的排产调度能力，整合生产计划、设备、人员三个维度，辅助调度员做出更合理的排产安排。

调度中心

智能调度 › 调度中心
菜单路径: 智能调度 → 调度中心 (/scheduling/overview)

调度中心是调度模块的总览仪表盘，一屏展示当前排产状态、产线负载和待处理事项。

用户看到什么

1
产线负载概览
以甘特图或进度条形式展示各产线当前和近期的排产负载，直观判断哪条产线有余量、哪条过载。
2
待排任务
未排入产线的生产计划以列表形式展示在侧边栏，调度员可拖拽或选择分配到具体产线和时间段。
3
告警与冲突提示
当排产出现时间冲突、人员不足、设备维护冲突时，顶部告警条会提示需要调整的计划。

调度计划

智能调度 › 调度计划
菜单路径: 智能调度 → 调度计划 (/scheduling/plans)

调度计划列表管理全部已创建的调度计划，支持创建新计划、查看计划详情和调整计划状态。

关键操作

1
查看计划列表
列表展示所有调度计划，包含：计划编号、计划日期、关联生产计划、状态（草稿/已发布/执行中/已完成）。支持按日期和状态筛选。
2
创建新调度计划
点击「新建计划」按钮（或从调度中心直接创建），选择计划日期、关联的生产计划和产线，配置人员分配后保存。路径：/scheduling/plans/create
3
查看计划详情
点击计划行进入详情页，查看完整的时间线、产线分配、人员安排。可在详情页内修改和发布计划。
调度与生产计划的关系 生产计划（Section 7）定义了「做什么、做多少」，调度计划在此基础上进一步确定「什么时间、哪条产线、谁来做」。调度计划创建后需发布才能生效，发布后相关人员可在 App 端看到当日排班。

补充模块 (Additional Modules)

工厂管理员 Web Admin

以下模块是系统运营中的辅助功能，涵盖质检标准配置、废弃处理、采购价格表、成品库存、考勤、部门管理、角色权限和系统日志等。按需使用。

质检标准管理

质量管理 › 质检标准
菜单路径: 质量管理 → 质检标准 (/quality/standards)

质检标准定义了不同产品或原料的质量检验项目和合格范围。创建质检记录时，系统会自动关联对应的质检标准。

关键操作

1
查看标准列表
列表展示全部质检标准，包含标准名称、适用对象（产品/原料类型）、检验项目数量、状态（启用/停用）。
2
创建质检标准
点击「新建标准」，填写标准名称、适用的产品或原料类型，然后逐项添加检验指标（如温度范围、微生物限值、外观要求等）及其合格范围。
3
编辑 / 停用标准
对已有标准可以修改检验项目和合格范围。停用后该标准不再出现在新建质检时的关联选项中，但历史记录不受影响。

废弃处理

质量管理 › 废弃处理
菜单路径: 质量管理 → 废弃处理 (/quality/disposals)

废弃处理记录不合格品的处置过程和结果。质检不合格后需创建废弃处理记录，确保不合格品有据可查。

关键操作

1
查看废弃记录
列表展示所有废弃处理记录，包含：关联质检单号、产品/原料名称、废弃数量、处理方式（销毁/退回供应商/降级使用）、处理日期。
2
创建废弃记录
点击「新建废弃处理」，选择关联的质检记录（或直接选择批次），填写废弃数量、处理方式和原因说明后提交。
溯源要求 食品安全法要求不合格品处理必须有完整记录。废弃处理记录会关联到质检记录和对应的生产批次，确保可追溯。

价格表管理

采购管理 › 价格表管理
菜单路径: 采购管理 → 价格表管理 (/procurement/price-lists)

价格表管理维护各供应商对不同原材料的报价信息，创建采购订单时系统自动引用最新价格。

关键操作

1
查看价格表列表
列表展示所有价格条目，包含：供应商名称、原料名称、单价、币种、有效期（起止日期）、最小起订量。支持按供应商或原料筛选。
2
新增 / 更新报价
点击「新增」按钮，选择供应商和原料，填写单价、有效期等信息。同一供应商和原料可以有多条历史报价，系统自动使用有效期内最新的一条。
3
价格对比
选择某种原料后，可以横向对比各供应商的报价和历史价格变化，辅助采购决策。

成品库存

销售管理 › 成品库存
菜单路径: 销售管理 → 成品库存 (/sales/finished-goods)

成品库存页面展示已完成生产并入库的成品库存情况，是出货管理的基础数据来源。

用户看到什么

1
成品库存列表
列表展示所有成品的当前库存：产品名称（SKU）、规格、批次号、库存数量、库位、入库日期、保质期截止日期。
2
库存预警
临近保质期的成品行以橙色标注，已过期的以红色标注。库存不足（低于安全库存）的产品也会高亮提示。
3
搜索与筛选
支持按产品名称搜索、按批次号精确查找、按库存状态（正常/预警/过期）筛选。

考勤管理

人事管理 › 考勤管理
菜单路径: 人事管理 → 考勤管理 (/hr/attendance)

考勤管理页面汇总展示员工的签到签退记录。数据来自 App 端员工的签到/签退操作。

用户看到什么

1
考勤记录列表
列表按日期展示每位员工的签到时间、签退时间、工时、出勤状态（正常/迟到/早退/缺勤）。
2
日期与员工筛选
顶部提供日期范围选择器和员工姓名搜索框，可查看特定员工或特定日期的考勤情况。
3
考勤统计
按月汇总的出勤天数、迟到次数、缺勤次数等统计数据，可导出用于薪资计算。
数据来源 考勤数据由 App 端员工操作产生。车间主管在 App 点击「签到」开始当班，「签退」结束当班。Web 端只做查看和统计，不支持手动补签。

部门管理

人事管理 › 部门管理
菜单路径: 人事管理 → 部门管理 (/hr/departments)

部门管理用于配置工厂的组织架构，创建和维护各部门信息。员工创建时需要关联所属部门。

关键操作

1
查看部门列表
以树形结构或平铺列表展示所有部门，包含部门名称、部门编号、上级部门、负责人、人数。
2
创建 / 编辑部门
点击「新增部门」，填写部门名称、编号、选择上级部门（可为空表示顶级部门）和部门负责人后提交。
3
删除部门
仅允许删除没有下级部门且没有关联员工的空部门。有员工的部门需先转移员工再删除。

角色管理

系统管理 › 角色管理
菜单路径: 系统管理 → 角色管理 (/system/roles)

角色管理页面配置系统中的角色和对应的权限。系统内置了常用角色（工厂管理员、调度员、仓储主管、车间主管等），管理员可查看和调整权限分配。

用户看到什么

1
角色列表
列表展示所有角色，包含：角色名称、角色代码（如 factory_super_admin、dispatcher 等）、描述、关联用户数。
2
权限配置
点击角色行的「权限」按钮，以树形勾选框形式展示所有功能模块和操作权限。勾选/取消勾选即可调整该角色的访问范围。
3
新建自定义角色
如果内置角色不满足需求，可以点击「新建角色」创建自定义角色并配置权限。
注意 修改角色权限后，已登录用户需要重新登录才能生效。内置角色（factory_super_admin 等）建议不要删除，可以修改其权限范围。

操作日志

系统管理 › 操作日志
菜单路径: 系统管理 → 操作日志 (/system/logs)

操作日志记录系统中所有关键操作的审计追踪，用于安全审计和问题排查。

用户看到什么

1
日志列表
列表按时间倒序展示操作日志，每条包含：操作时间、操作人、操作类型（创建/修改/删除/登录/导出）、操作模块、操作内容摘要、IP 地址。
2
搜索与筛选
支持按操作人、操作类型、时间范围和关键词搜索。例如，可以筛选「删除」类型的操作来审计数据删除行为。
3
日志详情
点击日志行可查看详细信息，包括操作前后的数据变化（对于修改操作）和完整的请求参数。

系统设置

系统管理 › 系统设置
菜单路径: 系统管理 → 系统设置 (/system/settings)

系统设置页面管理当前工厂的基础配置、通知配置和安全配置。配置项按分类分组为多个 Tab 页签。

配置分组

1
基础设置
工厂名称、工厂编号、联系方式、地址等基本信息。修改后全局生效（如报表中的工厂名称）。
2
通知设置
配置系统通知的发送规则，如：库存低于安全线是否发送提醒、设备告警是否推送到 App、质检不合格是否通知管理员等。
3
安全设置
密码策略（最小长度、过期时间）、登录安全（失败锁定次数）等安全相关配置。
建议 新工厂接入后第一步应完善基础设置中的工厂信息，确保报表和打印输出的工厂名称正确。通知设置可根据实际管理需求逐步启用。
