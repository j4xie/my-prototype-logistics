Step 7.3: 生成调拨单（核心步骤）

调拨单是连接「排产」和「仓储」的桥梁。生成调拨单后，系统自动根据 BOM 配方计算所有原辅料需求，并通知仓库备货。
1
在计划列表中找到刚创建的计划
可使用搜索框输入计划编号或产品名称搜索，也可按状态筛选「待执行」。
确认计划状态为「待执行」— 只有此状态才能生成调拨单。
2
点击该行操作列中的黄色文字「生成调拨单」按钮
操作列中有多个按钮（从左到右）: [查看] [转为批次] [生成调拨单] [开始] [取消]。
找到黄色字样的「生成调拨单」并点击。
3
确认对话框
弹出确认框，显示信息:
"确定为计划 "PP-20260328-001" 生成调拨单？
将根据 BOM 配方自动计算所需原辅料及包材，生成调拨申请发送给仓库。"
点击蓝色「生成」按钮确认。
系统后台自动执行以下操作（约 1-3 秒完成）:

第 1 步 — BOM 展开: 读取该 SKU 绑定的 BOM 配方 (转换率表)，根据计划数量反算每种原料的需求量。
    计算公式: 原料需求量 = 计划产量 / 转换率 x (1 + 损耗率)
    例如: 200kg 墨鱼圈，转换率 0.80，损耗 5% → 需要墨鱼 200/0.80 x 1.05 = 262.5 kg

第 2 步 — FEFO 库存校验: 检查仓库当前库存是否足够，按先到期先出 (First-Expire-First-Out) 原则分配批次。

第 3 步 — 创建调拨单: 生成一张 InternalTransfer 调拨单，包含所有原辅料的行项目 (line items)，每项标注: 物料名称、需求数量、单位。

第 4 步 — 自动提交审批: 调拨单状态设为「已申请」(REQUESTED)，自动推送给仓库端。仓储主管在手机 App 上会看到新的待处理调拨。
4
查看操作结果
成功时: 顶部绿色提示「调拨单已生成，共 N 项物料，等待仓库审批」。
可在「调拨管理 → 调拨单列表」页面查看新生成的调拨单详情。
可能的错误及处理:
"该产品无BOM配置" — 选择的产品没有配置转换率/BOM。解决: 先到「生产管理 → 转换率配置」为该产品添加 BOM（见第一部分 Section 5B）。
"产品类型不存在" — 选择的产品已被删除或ID无效。解决: 重新选择正确的产品类型。
网络错误 — 检查网络连接后重试。
操作列中其他按钮说明:
[转为批次] — 将计划直接转为生产批次（不走调拨流程，适用于车间已有物料的情况）。
[开始] — 将计划状态改为「进行中」，表示已开始执行。
[完成] — (进行中状态才显示) 弹窗输入实际产量后完成计划。
[取消] — 弹窗输入取消原因后取消计划。

Step 8.4: 物理备货 + 系统确认发运

1
在仓库中按清单实际备货
审批通过后，仓管员在物理仓库中:
- 按照 FEFO 原则（先到期先出）拣选物料
- 检查保质期标签
- 称重核对数量
- 将备好的物料放到发货区
2
物理备货完成后，在 App 中点击「确认发运」按钮
此操作表示物料已经从仓库发出，准备交给车间。
点击后状态变更为「已发运」(SHIPPED)。
系统在确认发运时自动执行以下操作:

FEFO 库存扣减:
- 系统自动从仓库库存中扣减本次发运的物料数量
- 按 FEFO 原则: 优先扣减最早到期的批次
- 例如: 需要 262.5kg 墨鱼，仓库有两批:
    批次 A: 到期日 4/15，库存 200kg → 全部扣减，剩余 0
    批次 B: 到期日 5/20，库存 300kg → 扣减 62.5kg，剩余 237.5kg
- 每个被扣减批次的 usedQuantity (已使用量) 相应增加
库存不足时:
如果实际库存不足以满足调拨需求，系统会阻断发运操作（报错「库存不足」），不会静默扣减到负数。
解决方法: 需要先完成原料入库（采购入库或其他调拨入库），确保库存充足后再点击「确认发运」。

Step 10.1: 进入工序操作页面

1
在首页找到「工序操作」快捷入口，点击进入
车间主管首页显示多个快捷操作卡片，找到「工序操作」并点击。
进入后页面标题为「工序操作」，顶部导航栏右侧有一个扫码图标（用于扫码定位，后面 Step 10.4 方式B 详述）。
2
在工序任务列表中选择要操作的工序
页面显示提示文字: "选择要操作的工序"
下方列出所有当前活跃的工序任务（状态为「进行中」「待开始」或「补充中」的任务），每个任务卡片显示:
卡片字段 含义 示例
工序名称 当前工序的名称 拆箱分拣
状态标签 蓝色圆角标签，显示当前状态 进行中 / 待开始
产品名称 对应的产品类型 CP-汇庭商贸-墨鱼圈
计划 / 完成 计划产量和已完成产量 计划: 200 kg   完成: 50
进度条 完成比例的可视化进度条 + 百分比 进度条填充 25% + 文字「25%」
3
点击选择一个工序（如「拆箱分拣」）
进入操作面板页面。页面标题变为该工序名称（如「拆箱分拣」）。
操作面板分为三大区域: 任务概况、员工签到/签退、报产量。
左上角返回箭头可回到工序列表重新选择。

Step 10.2: 操作面板 — 任务概况区域

1
页面最上方: 任务概况卡片
显示当前工序的核心数据，一目了然:
指标 含义 示例
计划 (单位) 本工序的计划产量 200 (kg)
已完成 已审批通过的累计完成量 50
待审批 已提交但尚未审批的报工量 45
剩余 计划量 - 已完成 - 待审批 = 尚需生产量 105

Step 10.3: 员工签到

员工签到记录谁在什么时间参与了哪道工序，是计算工时和人工成本的基础数据。
1
在操作面板中找到「员工签到/签退」区域
该区域显示两个按钮: 绿色「扫码签到」和红色「扫码签退」。
2
点击绿色「扫码签到」按钮
手机摄像头自动打开，进入扫码界面。
3
扫描员工工牌上的二维码
将摄像头对准员工工牌上的二维码。工牌二维码格式为 CRETAS:EMP:{员工ID}:... 或员工工号字符串。
系统识别二维码 → 查找对应的员工信息 → 自动执行签到。

工牌生成方式: 管理员在 Web Admin「系统管理 → 员工工牌生成」页面为员工生成并打印工牌。
4
确认签到结果
成功: 弹出对话框提示 "签到成功 -- 陈工 已签到「拆箱分拣」"，点击「确定」关闭。
失败 — 未识别: 提示 "无法识别此工牌"，检查工牌是否正确或已过期。
失败 — 已签到: 如果该员工已经在此工序签到，系统会提示重复签到。
5
为所有参与本工序的员工逐一重复步骤 2-4
每位员工依次扫码签到。签到后，该员工会出现在「报产量」区域的已签到员工列表中（蓝色标签形式）。
签到数据用途:
1. 确定谁参与了哪道工序（人员追溯）
2. 报工时从已签到列表选择员工（确保报工关联到人）
3. 签退时自动计算工时（签到时间 → 签退时间）
4. 管理员查看考勤报表时的数据来源

Step 10.4: 报产量（三种方式）

报产量（报工）是记录每道工序产出数量的核心操作。系统支持三种报工方式，适用于不同场景。建议优先使用方式 A。

方式A 从已签到员工列表选择（推荐）

1
在操作面板中找到「报产量」区域
区域顶部显示「选择员工(已签到)」标签，下方以蓝色圆角标签 (Chip) 形式显示所有已签到的员工名字。
例如: 陈工 李工 王师傅
如果没有看到任何标签，说明该工序还没有员工签到，需先执行 Step 10.3 签到操作。
2
点击选择一位员工标签（如「陈工」）
选中后显示: "报工员工: 陈工 [更换]"
点击 [更换] 可以重新选择其他员工。
3
在「产出数量」输入框中填写本次报工数量
输入框下方有快捷按钮:
快捷按钮 含义 示例
[剩余量] 自动填入当前剩余的未完成数量（计划量 - 已完成 - 待审批） 点击填入 105
[一半] 自动填入剩余量的 50% 点击填入 52.5
4
（可选）在「备注」字段添加说明
例如: "9:00-10:00 批次"、"半成品暂存"等。此字段不是必填的。
5
点击「提交报工」按钮
成功: 弹出对话框提示 "报工成功 -- 拆箱分拣 -- 50 kg"
对话框有两个按钮:
[继续] — 留在当前页面继续报工（清空数量和备注，可选择下一位员工）
[返回] — 返回工序列表页面

失败: 如果数量为空、为 0 或负数，提示「请输入有效的产出数量」，不会提交。

方式B 扫码定位（适合车间巡视时操作）

1
在工序列表页面（尚未选择工序时），点击右上角扫码图标
注意: 此扫码图标在工序列表页面的标题栏右侧，不是进入某个工序后的签到扫码。
此操作的模式是「扫码定位」(locate) — 扫描员工工牌后自动找到该员工所在的工序。
2
扫描员工工牌二维码
系统自动查询该员工当前签到在哪道工序。
3
系统自动跳转 + 自动选中员工
成功: 自动跳转到该员工签到的工序操作面板，且报工区域已自动选中该员工。
主管只需输入数量 → 提交即可。

未找到: 提示 "XX 没有进行中的签到记录，请先签到" — 表示该员工尚未在任何工序签到。
方式B 的适用场景: 车间主管在车间巡视时，直接扫描正在工作的员工工牌，系统自动定位到该员工的工序，无需手动在列表中寻找工序再选择员工。效率高于方式A。

方式C 主管自己报（不关联具体员工）

1
在操作面板的「报产量」区域，点击「主管自己报」按钮
选中后显示: "报工员工: 主管自己 [更换]"
此模式下报工数据不关联到具体的一线员工，仅记录在主管名下。
2
输入数量 → 提交报工
操作流程与方式A 的步骤 3-5 相同。
区别: 报工记录的 targetWorkerId 不会关联到实际员工。
方式C 的适用场景: 无法确定具体是哪位员工的产出时（如多人协作无法区分个人产量），或者员工忘记扫码签到但产量需要及时记录。
建议: 尽量使用方式A 或方式B，确保报工数据关联到具体员工，便于后续计算人效和人工成本。

Step 10.4 补充: 累计报工机制

报工是累计的，不是覆盖的:
同一个工序、同一天内可以多次报工。每次提交都会创建一条独立的报工记录。

示例:
9:00 报工: 陈工 50 箱
10:30 报工: 陈工 45 箱
12:00 报工: 李工 60 箱
系统累计: 50 + 45 + 60 = 155 箱（显示在工序概况的「待审批」中）

审批流程: 每笔报工记录都需要管理员在 Web Admin「生产管理 → 报工审批」页面逐一审批。审批通过后才计入「已完成」数量。

Step 10.5: 员工签退

1
当天工作结束后，在操作面板的「员工签到/签退」区域点击红色「扫码签退」按钮
手机摄像头打开，进入扫码界面。
2
扫描员工工牌二维码
系统查找该员工在当前工序的签到记录。

成功: 弹出对话框提示 "签退成功 -- 陈工 已签退「拆箱分拣」"
失败 — 未找到签到记录: 提示 "陈工 未签到此工序" — 如果该员工没有在此工序签到，则无法签退。检查员工是否签到在其他工序。
3
对每位已签到的员工逐一扫码签退
确保所有参与生产的员工在下班时全部签退。
签退时系统自动计算工时:
签到时间: 2026-03-28 08:00 → 签退时间: 2026-03-28 17:00 → 工时: 9 小时
此数据用于: HR 考勤统计、人工成本分摊到 SKU。
忘记签退: 如果员工下班忘记签退，系统不会自动补签退。需要主管联系管理员在后台手动处理，或者次日签到前由系统提示异常。

11.4 工序投入产出对比

菜单路径: 生产管理 → 工序投入产出对比
1
左侧菜单: 生产管理 → 工序投入产出对比
显示每道工序的投入和产出对比，用于分析各工序的转换效率和损耗情况。
内容 说明
工序列表 按生产流程顺序列出所有工序: 拆箱分拣 → 清洗去内脏 → 切圈 → 裹粉 → 包装 等
投入量 (Input) 进入该工序的物料总量（上一道工序的产出 或 原料领用量）
产出量 (Output) 该工序完成后的合格品数量
转换率 产出量 / 投入量 x 100%。反映该工序的物料转化效率。
损耗量 投入量 - 产出量。即该工序的物料损失。
分析价值:
- 如果某道工序转换率持续偏低，说明该工序损耗过大，需排查原因（设备问题、操作不当、原料质量等）
- 对比不同班次、不同操作人员在同一工序的转换率，找出最佳实践
- 为 BOM 转换率的调整提供实际数据依据

12.3 常见问题 (FAQ)

Q1: 点击「生成调拨单」报错 "该产品无BOM配置"
原因: 选择的产品 (通常是基础模板而非 SKU) 没有配置 BOM 转换率。
解决:
1. 确认排产时选的是 SKU (带 "CP-" 前缀)，不是基础模板
2. 如果确实是 SKU，检查是否已配置转换率: 到「生产管理 → 转换率配置」查看
3. 如果没有转换率，需先为该产品配置 BOM（见第一部分 Section 5B 配置 BOM 转换率）
4. 配置完成后重新生成调拨单
Q2: 仓储发货时报错 "库存不足"
原因: 仓库中该原料的可用库存量不足以满足调拨需求。
解决:
1. 检查原料是否已完成入库: 到「仓储管理 → 原材料批次」查看库存
2. 如果是采购的新物料尚未入库，需先完成采购入库操作（见第一部分 Section 6B 原料入库）
3. 如果库存确实不够，需联系采购补货，或调整生产计划数量
4. 库存充足后再回到调拨单点击「确认发运」
Q3: 员工扫码签到失败，提示 "无法识别此工牌"
原因: 工牌二维码无法解析为有效的员工信息。
排查步骤:
1. 确认工牌是否是系统生成的（在 Web Admin「系统管理 → 员工工牌生成」页面生成）
2. 确认该员工已在「人事管理 → 员工管理」中创建且处于启用状态
3. 确认工牌没有破损导致二维码不可读
4. 尝试在光线充足的环境下重新扫码
5. 如果工牌损坏，需要在 Web Admin 重新生成并打印
Q4: 在报工界面看不到已签到员工列表（蓝色标签为空）
原因: 该工序当前没有员工签到。
解决:
1. 员工必须先扫码签到（Step 10.3）才会出现在列表中
2. 确认签到的工序与当前选择的工序一致（员工签到了「拆箱分拣」但你看的是「包装」）
3. 尝试点击返回后重新进入该工序，触发数据刷新
4. 如果不需要关联员工，可使用「方式C: 主管自己报」
Q5: 报工提交后在哪里审批？
审批入口: 管理员登录 Web Admin → 左侧菜单「生产管理 → 报工审批」
审批列表显示所有待审批的报工记录，管理员可逐一通过或驳回。
只有审批通过的报工才会计入工序的「已完成」数量。
Q6: BOM 达成率显示为 0% 或全部为空
原因: 车间主管没有录入实际原料用量（Step 9.2）。
解决: 必须在 App 中进入批次详情 → 点击「原料领料」→ 为每种物料录入实际用量。
没有实际用量数据，系统无法计算达成率。
Q7: SKU 毛利率显示为 0 或数据不完整
可能原因及解决:
1. 缺少原料成本: 检查原料入库时是否录入了单价 → 在「仓储管理 → 原材料批次」中查看
2. 缺少实际用量: 同 Q6，需录入 BOM 实际用量
3. 缺少销售价格: 需在客户定价或 SKU 配置中设置销售单价
4. 缺少人工工时: 员工需完成签到+签退，系统才能计算人工成本
Q8: 员工签退提示 "未签到此工序"
原因: 该员工没有在当前选择的工序中签到，或者已经签退过了。
排查:
1. 确认员工签到的是哪道工序（可能签到了其他工序）
2. 使用扫码定位功能（工序列表页右上角扫码图标）扫描员工工牌，系统会显示该员工签到的工序
3. 如果确实没有签到记录，可能是签到时操作失败或从未签到
Q9: 如何修改已提交的报工数量？
已提交的报工记录无法直接修改。如果数量有误:
1. 如果尚未审批: 让管理员在 Web Admin 驳回该笔报工
2. 在 App 中重新提交正确的数量
3. 如果已审批通过: 需联系管理员在后台处理
Q10: 调拨单审批后能否撤回？
审批通过但尚未发运的调拨单，在 Web Admin 的「调拨管理 → 调拨单列表」中可以进行取消操作。
已经确认发运的调拨单（库存已扣减），无法直接撤回，需要管理员通过反向调拨或库存调整来处理。
