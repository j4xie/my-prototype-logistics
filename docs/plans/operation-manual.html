二、首次配置（只做一次）

🏭 管理员 Web Admin

2.1 导入客户

1
销售 → 客户管理 → 导入
上传客户 Excel，或逐个新增。如: 汇庭商贸、酒拾烤肉

2.2 创建原料类型

1
系统管理 → 原料管理 → 新增
填写: 名称(墨鱼)、单位(kg)、分类(海产)、存储方式(冷冻)

2.3 创建产品模板

1
系统管理 → 产品管理 → 新增产品
填写: 编码(YYQ)、名称(墨鱼圈)、单位(kg)、分类(成品)
不填客户 — 这是基础模板

2.4 配置 BOM 转换率

1
生产管理 → BOM → 转换率 → 新建
产品: 墨鱼圈 | 原料: 墨鱼 | 转换率: 0.80 | 损耗: 5%
产品: 墨鱼圈 | 原料: 食盐 | 转换率: 50.0 | 损耗: 0%
每种原料配一条记录
转换率含义: 转换率=0.80 表示 1kg 原料产出 0.80kg 成品。即生产 1kg 成品需要 1/0.80=1.25kg 原料。

2.5 组装 SKU ⭐

1
产品管理 → 点黄色「SKU组装」按钮
2
选择产品模板 → 选择客户 → 点「创建SKU」
系统自动: 克隆模板 + 绑定客户 + 复制配方
生成: CP-汇庭商贸-墨鱼圈
💡 也可以用 AI: 在对话框说 "给汇庭创建墨鱼圈SKU"
之后排产时选 SKU（不是模板），BOM 自动从 SKU 的配方展开。

三、排产 + 生成调拨单

🏭 管理员/调度员 Web Admin 前一天下午

1
生产管理 → 生产计划 → 新建计划
产品: 选 SKU (如 CP-汇庭商贸-墨鱼圈)
计划量: 200kg
计划日期: 明天
2
计划列表 → 操作列 → 点「生成调拨单」
⚡ 系统自动:
① BOM 展开计算原辅料需求 (含损耗)
② FEFO 库存校验 (先到期先出)
③ 创建调拨单 (状态: 已申请)
④ 推送给仓库审批

四、仓储审批 + 发货

📦 仓储主管 手机 App

1
首页 → 点橙色「领料调拨」卡片
看到待处理调拨单列表
2
点击调拨单 → 查看物料明细
显示: 原料名称、数量、单位
3
审批通过 → 状态变为「已批准」
4
备货完成后 → 点「发货」
⚡ 系统自动: FEFO 扣减原料库存。库存不足则阻断发货。

五、车间签收 + 领料确认

🔧 车间主管 手机 App 当天早上

5.1 签收物料

1
底部「批次」Tab → 物料调拨
找到调拨单 → 核对实物 → 点「签收」→ 点「确认」
⚡ 系统自动: 工厂仓创建新原料批次

5.2 录入实际用量

1
批次详情 → 点蓝色「原料领料」按钮
2
查看 BOM 物料清单 → 逐个点「录入实际用量」
弹窗输入实际用了多少 → 有快捷按钮(计划量/95%)
3
刷新查看达成率
如: 97.8% 🟢

六、生产报工

🔧 车间主管 手机 App 当天 8:00-17:00

6.1 员工签到

1
首页 → 工序操作 → 选工序（如「拆箱分拣」）
2
绿色「扫码签到」→ 扫描员工工牌二维码
提示: "签到成功 — 陈工 已签到「拆箱分拣」"

6.2 报产量（三种方式）

方式A — 从列表选员工（推荐）:
报产量区域自动显示已签到员工蓝色标签 → 点击标签选中 → 输入数量 → 提交
方式B — 扫码定位:
工序列表页右上角扫码图标 → 扫员工工牌 → 自动跳转到该员工的工序 + 员工已选中
方式C — 主管自己报:
点「主管自己报」按钮 → 输入数量 → 提交（不关联具体员工）
💡
每小时报一次，系统自动累加。每笔报工需后台审批。

6.3 员工签退

1
红色「扫码签退」→ 扫描员工工牌
系统自动计算工时: 签到8:00 → 签退17:00 = 9小时

七、查看分析

🏭 管理员 Web Admin

分析项入口内容
BOM达成率生产管理 → BOM达成率每批次每种物料: 计划量 vs 实际量 vs 差异%
SKU毛利率财务 → SKU毛利率原料成本+人工成本 vs 销售收入 = 毛利率
原料价格趋势库存 → 原料价格趋势移动平均价 + 各批次入库价格折线图
工序IO对比生产管理 → 工序IO对比每道工序投入产出比
