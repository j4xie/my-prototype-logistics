## 二、调度员/管理员操作 (Web Admin)

### 2.1 生成调拨单

**前提**: 已创建生产计划 + 产品已配置 BOM 转换关系

1. 登录 Web Admin (`factory_admin1 / 123456`)
2. 进入 **生产管理 → 生产计划**
3. 找到状态为 **PENDING** 或 **PLANNED** 的计划
4. 点击操作列的 **「生成调拨单」** 按钮
5. 弹窗确认 → 系统自动:
   - BOM 展开计算所需原辅料
   - FEFO 库存校验
   - 创建 InternalTransfer (状态: REQUESTED)
   - 自动提交给仓库审批
6. 成功提示: "调拨单已生成，共 N 项物料，等待仓库审批"

### 2.2 查看调拨状态

- 仓储Tab有调拨列表，或通过 **库存管理 → 内部调拨** 查看

## 三、仓储主管操作 (Mobile App)

### 3.1 查看待处理调拨

1. 登录 RN App (`warehouse_mgr1 / 123456`)
2. 首页可见 **「领料调拨」** 橙色入口卡片
3. 点击进入调拨列表

### 3.2 审批 + 备货 + 发货

1. 点击一条「已申请」的调拨单
2. 查看物料明细 (原料名称/数量/单位)
3. 操作:
   - **审批通过** (approve) → 状态变为「已批准」
   - **备货完成后发货** (ship) → 状态变为「已发运」
   - ⚡ 系统自动扣减物流仓原料库存 (FEFO 先到期先出)

### 3.3 驳回

- 如物料不足可驳回 (reject)，填写原因
- 调度员可调整后重新生成

## 四、车间主管操作 (Mobile App)

### 4.1 签收物料

1. 登录 RN App (`workshop_sup1 / 123456`)
2. 进入 **批次管理 Tab → 物料调拨**
3. 找到「已发运」的调拨单
4. 点击 → **签收** (receive) → **确认** (confirm)
5. ⚡ 系统自动为工厂仓创建新原料批次

### 4.2 录入实际用量 (领料确认)

1. 进入 **批次详情** → 点 **「原料领料」** 按钮
2. 查看 BOM 物料清单:
   - 物料名称 | 计划量 | 实际量 | 达成率
3. 点击任意物料的 **「录入实际用量」**
4. 底部弹窗:
   - 显示计划量 + 已录入量
   - 输入实际用量 (有快捷按钮)
   - 点「确认录入」
5. 刷新后查看更新的达成率

### 4.3 报工 (员工选择两种方式)

**方式1: 从列表选**
1. 工序操作 → 选工序 → 报产量区域
2. 已签到员工显示为蓝色标签
3. 点击标签选中 → 输入数量 → 提交

**方式2: 扫码定位**
1. 工序列表页 → 右上角扫码图标
2. 扫描员工工牌
3. 自动跳转该员工签到的工序 + 员工已选中

## 五、AI 对话 (任意角色)

在 AI 对话框可直接问:
- "生产1000kg带鱼段需要多少原料？" → 自动 BOM 展开 + 库存校验
- "检查库存够不够生产这批" → 返回缺口明细
- "帮我算物料需求" → 返回物料清单

## 六、数据依赖 (首次使用前必须配置)

| 数据 | 配置位置 | 说明 |
|------|---------|------|
| 产品类型 | Web Admin → 产品管理 | 如: 墨鱼圈、带鱼段 |
| 原辅料类型 | Web Admin → 原料管理 | 如: 墨鱼、带鱼、食盐 |
| BOM 转换关系 | Web Admin → 产品工序关联 / BOM | 每种产品需要哪些原辅料、用量、损耗率 |
| 原料库存 | 仓储 → 入库操作 | material_batches 表有库存 |
| 员工工牌 | 系统管理 → 员工管理 | 员工 employeeCode 或 NFC 标签 |
