## 案例背景

- **产品**: 墨鱼圈 (ProductType: CP-墨鱼圈-500g)
- **计划量**: 200kg
- **BOM 配方** (material_product_conversions 表):
  - 墨鱼 — 标准用量 1.2kg/kg成品, 损耗率 5% → 实际需 252kg
  - 食盐 — 标准用量 0.02kg/kg成品, 损耗率 0% → 实际需 4kg
  - 淀粉 — 标准用量 0.08kg/kg成品, 损耗率 2% → 实际需 16.3kg
  - 包装袋 — 标准用量 2个/kg成品, 损耗率 3% → 实际需 412个
- **物流仓库存**: 墨鱼 300kg(批次MB-0326-01, 到期4/15) + 100kg(批次MB-0320-01, 到期4/10)
- **参与人员**: 张权(调度), 王师傅(仓储), 李师傅(车间主管), 陈工/赵工(操作员)

### 步骤 1.3 — 生成调拨单 ⭐ 核心新功能

```
操作: 在计划列表找到 PP-20260326-0001 → 操作列 → 点「生成调拨单」
弹窗: "确定为计划 PP-20260326-0001 生成调拨单？将根据BOM配方自动计算所需原辅料。"
点击: 「生成」

系统自动执行:
  1. 读取产品「墨鱼圈-500g」的 BOM 配方
  2. 按 200kg 计划量展开计算:
     - 墨鱼: 200 × 1.2 × (1 + 0.05) = 252 kg
     - 食盐: 200 × 0.02 × (1 + 0) = 4 kg
     - 淀粉: 200 × 0.08 × (1 + 0.02) = 16.32 kg
     - 包装袋: 200 × 2 × (1 + 0.03) = 412 个
  3. FEFO 库存校验:
     - 墨鱼需252kg, 库存400kg(300+100) ✅ 充足
     - 优先使用 MB-0320-01(到期4/10, 100kg) → 再用 MB-0326-01(到期4/15, 152kg)
  4. 创建调拨单 TRF-20260326-xxxx:
     - 类型: HQ_TO_BRANCH (物流仓→工厂仓)
     - 状态: REQUESTED (已申请)
     - 关联计划: PP-20260326-0001
     - 4个行项目 (墨鱼252kg + 食盐4kg + 淀粉16.32kg + 包装袋412个)

结果提示: "调拨单已生成，共 4 项物料，等待仓库审批"
```

## 第零阶段: 基础数据 + SKU组装 (首次使用前)
